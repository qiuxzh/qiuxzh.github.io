Java Web 期末考试题型与复习重点

一、考试题型（总分 100 分）

大题 题型 题量 分值 备注
第一题 单选题 10 小题 10 分（每题 1 分） 基础概念题
第二题 简答题 5 题 30 分 每题分值不固定，按难度分配
第三题 程序分析题 4 题 20 分 每题分值不固定
第四题 程序设计题 3 题 40 分 按难度有分值差异。

老师说题型和分值细节之后会发到班级群里，课上先口头讲一遍，不用抄。

二、出题范围

教材第 1 章到第 6 章 + 第 10 章，共 7 个章节。

  • 没点名的章节不用复习，一定不考，不必“顺便看看”。
  • 范围就是课堂上讲过的内容；教材看不看不是关键，以群文件里的课件为主。

三、逐章复习重点

第一章　Java Web 开发环境的构建

  • 对应复习材料：作业一、作业二。这两份作业本身就是选择题 + 简答题，正好覆盖本章考法。
  • 本章只出选择题和简答题，不会出分析题、设计题。
  • 不考原题，题面会调整修改；把作业理解透就没问题。
  • 教材本章可以不看，直接看群文件课件里编号 01《Web 开发基础知识》和 02《Web 开发环境配置》两份。

第二章　JSP 语法

位置 复习内容 要求
教材 P10，2.1（2.1.1） JSP 页面的基本构成 说出四种基本元素及各自作用：HTML 标记（JSP 的模板元素，定义页面结构）、JSP 注释、脚本元素（声明、程序片、表达式）。JSP 里既有 HTML 代码也有 Java 代码，要能区分哪部分是模板、哪部分是 Java
教材 P13，2.2.2 成员变量与方法的声明，即 JSP 声明 语法格式 + 主要功能；重点看 P13–14 的例 2-3，能说明“给一段代码输出什么、为什么这样输出”。
  • 本章配套课件是群文件“第四部分 JSP 技术”。
  • 考法上偏“读代码说结果 + 解释原因”，考的是对 JSP 声明原理的理解，不是背例题。

第三章　JSP 内置对象（不单独出题）

本章不会单独出题，但程序设计题、程序分析题里可能用到，所以只需抓两个点：

位置 对象 要点
教材 P25 request 数据存取
教材 P31 session 数据存取。
  • 两者本质都是域对象，用 setAttribute 保存数据、getAttribute 取数据，可实现跨页面的数据传递与共享。
  • 关键提醒：这两个对象虽然写在“JSP 内置对象”这一章，但不限于 JSP 使用，Servlet 里同样能用，题目会涉及，别把思路局限在 JSP 里。
  • 复习方式：直接回看实验里用到 request / session 的部分即可，教材上的案例看与不看都行（性价比不高）。

第四章　JSP 与 JavaBean

位置 复习内容 要求
教材 P46，4.1 JavaBean 编写规范（例 4-1） JavaBean 就是一个 Java 类：定义属性 + 提供 getter / setter，是模板化写法。程序设计题可能要求手写一个 JavaBean，但一定是换过内容的，不能背例 4-1
教材 P47，4.2 JSP 中三个动作标记 4.2.1 useBean（创建 JavaBean 对象）、P49 4.2.2 getProperty（取属性）、P50 4.2.3 setProperty（设属性）。
  • 三个动作标记的含义不用死记，标记名本身说明了功能。
  • 要参考案例就看 P51 例 4-4，它把 useBean、setProperty、getProperty 三个都用上了；看懂这个案例就够了。

第五章　Servlet（本次考试分量最重的一章）

1. 两种部署方式（= 配置 Servlet 访问路径）：

位置 方式
教材 P55，5.2.1 通过 web.xml 配置文件配置
教材 P56，5.2.2 基于注解（@WebServlet）在 Servlet 类上直接配置。
  • “部署 Servlet”和“配置 Servlet 访问路径”是同一件事，两种说法都要认得。
  • 为什么要配置：Servlet 的存放路径和 HTML、JSP 页面不一样，不配置访问路径外部就访问不到服务器上的 Servlet 程序。

2. Servlet 生命周期（P58，5.3 节，重点中的重点）：

阶段 方法 调用次数
初始化 init() 只调用 1 次（Servlet 初始化时）
运行 service() 每访问一次就调用 1 次，多次
销毁 destroy() 只调用 1 次（Servlet 销毁 / 服务器关闭时）。
  • 参考教材 P58 例 5-3。老师提示：该例里 destroy 方法有，但没有输出语句，可以自己补一行输出，观察控制台打印顺序。
  • 典型程序分析题：给一个含 init / service / destroy 的 Servlet，连续访问多次，让你写出控制台输出结果并解释原因——本质上就是考三种方法的调用特点。

3. 重定向与转发（P63，5.6 节）：

方式 实现 位置
重定向 response.sendRedirect(...) P63，5.6.1
请求转发 request.getRequestDispatcher(...).forward(...) P64，5.6.2。
  • 两者都是“从一个页面跳到另一个页面”，区别在于重定向与请求转发的方式不同。
  • 程序设计题里必然涉及页面跳转，两种至少会写一种，并知道它们的功能。

4. Cookie 与 Session 会话技术（P66，5.7 节）：

  • 教材这一节只写了 session cookie，课堂上讲得更多，要看课件第三部分“Servlet 开发”。
  • 重点看课件第 51 页“医院就医卡”案例，以及浏览器与服务器之间基于 cookie 和 session 交互的示意图（老师之后会放动态版 PPT）。
  • 要求：能描述并解释 cookie 和 session 如何实现会话状态的保持，即两者的实现原理。session 在实验里一定用过，必须掌握。

5. MVC 设计模式（P69，5.8 节）：

  • 三个字母的含义：Model 模型、View 视图、Controller 控制器；以及三者各自的功能。
  • 图 5-6 给出三部分对应的实现技术：
角色 实现技术 职责
视图 View JSP 或 HTML 页面展示
控制器 Controller Servlet 流程控制、接收并处理用户请求
模型 Model JavaBean 业务逻辑处理、数据库操作与交互。
  • 考法灵活：给一个实际案例（如某管理系统），问“用户信息提交页面属于 MVC 的哪一部分”“接收请求并处理信息属于哪一部分”“数据库操作属于哪一部分”，要能对号入座。

第六章　过滤器 Filter（只考 1 个选择题）

  • 上机课只讲了过滤器，监听器没讲，不考也不用看。
  • 看教材 P75，6.1 节上面那一段文字即可：知道 Filter 是什么、主要功能是什么。
  • 本章只出一道基本概念选择题，不会更深；实际开发中的 Filter 用法另说，考试不涉及。

第十章　Ajax（只考 1 个选择题）

  • 本章只讲了 Ajax 和 JSON，但只考 Ajax，JSON 不考。
  • 看教材 P149 的 10.1.1 和 P150 的 10.1.2 两个小节：Ajax 是什么、实现什么功能、核心是什么。
  • 同样只出一道基本概念选择题，后面的内容不用看。

四、程序设计题（3 题，40 分）

复习材料：实验二（用户模块功能实现：注册、登录、注销），这是设计题的模板来源。

标准处理链路（几乎所有功能模块都套这一套）：

  1. 用户信息提交表单（HTML 或 JSP 都可以）；
  2. 表单提交给 Servlet（即 MVC 中的控制器）；
  3. Servlet 接收并处理信息；
  4. 处理完跳转到 JSP 页面显示结果。

评分口径：

  • import 导包语句可以省略不写，不抠语法细节；
  • 但类的定义、核心处理代码、基本框架要写出来；
  • 重点看是否体现 MVC 设计思想以及处理逻辑是否清楚。

题目一定会换功能，要举一反三：会了一个模块，其他模块按同样逻辑套用即可。

五、程序分析题（4 题，20 分）

只有两种形式：

  1. 给代码，分析结果：说出程序输出什么，并解释产生这个结果的原因；
  2. 补全代码：给出代码片段和功能要求，把缺失部分补全。

涉及知识点即上文各章的标注内容（JSP 声明、Servlet 生命周期、重定向与转发、MVC 等）。

六、老师的收尾提醒

  1. 千万不要死记硬背——作业、实验、教材案例都一样，一切建立在理解之上，题目一定不是原题。
  2. 没点名的章节不用看，一定不考；点到的范围已经讲得很全很细，按这个复习就够。
  3. 教材不是必读，主要看群文件课件；课件已全部发在群文件“课件”文件夹。
  4. 设计题的代码只要能写出处理逻辑和核心代码即可，不追求语法完美。
  5. 之后还有问题可以继续找老师沟通。

附：按分值排的复习优先级

优先级 内容 对应分值
最高 实验二 + MVC 链路（设计题） 40 分
高 第五章 Servlet（部署方式、生命周期、重定向/转发、Cookie 与 Session、MVC） 简答 + 分析题主力
中 第二章 JSP 声明与页面构成、第四章 JavaBean 与三个动作标记 简答 + 分析题
中 第三章 request / session 域对象（不单独出题，服务于分析与设计题） 间接
低 第六章 Filter、第十章 Ajax（各 1 个选择题） 2 分
低 第一章：只看作业一、作业二 选择题 + 简答题。
