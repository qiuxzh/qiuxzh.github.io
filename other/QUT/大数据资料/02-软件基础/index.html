02 软件基础

qiuxz2026-11-162026-11-16

Hadoop、Spark、Hive、Kafka……这些名字背后，有没有一个共同点？

有：它们几乎全跑在 Linux 上。你在 Windows 上装 Hadoop 得先装个模拟层，装 Spark 要先配环境变量和 SSH，折腾半天还可能跑不起来。

原因很朴素：大数据集群动辄上百台机器，需要稳定、免费、能批量远程管理，还要求长时间不重启的操作系统。Linux 四条全占。所以这门课先讲 Linux，再讲大数据。工具是长在地基上的。

Linux 到底是什么

Linux 是一个操作系统（Operating System），和 Windows、macOS 是同一类东西。

但它出现在你想不到的地方：跑着整个互联网的服务（从 Google 搜索到各大网站的服务器）；跑在大量设备里（手机、电视、路由器，甚至汽车）；也可以装在你自己的电脑上。

图 2-1　企鹅 Tux 是 Linux 的吉祥物，也是它最出名的标志

一段必须知道的历史

时间 人物 / 地点 事件
1969 Ken Thompson、Dennis Ritchie，贝尔实验室 写出 UNIX，现代操作系统的祖师爷
1983 Richard Stallman 发起 GNU 计划，要做一个自由的操作系统
1991 Linus Torvalds，芬兰赫尔辛基大学学生 写了一个 内核（kernel），放在网上供人免费使用，取名 Linux
1994 — Linux 1.0 发布，采用 GPL 协议：可以免费用、改、再分发

Linus 当时是对 MS-DOS 不满，想给自己的新电脑弄一个免费的、类 UNIX 的系统，于是动手写了内核。它是一个学生为了解决自己的问题做出来的，不是被公司立项做出来的。

Linux 里面长什么样

Linux 由三部分组成。

组成 干什么的 举例
内核
Kernel		 最基本的功能：管理进程、内存、驱动、文件系统和网络，直接决定性能与稳定性 Linux 内核本身（Linus 写的那个）
系统程序
Shell / Utilities		 随系统提供的工具与命令，让用户能操作内核 bash、ls、cp、vim
应用程序
Applications		 你要用的软件 浏览器、Python、Spark

关键在内核和用户的分界：内核管资源，用户不能直接操作它，必须通过「系统调用」请它代劳。这条分界线叫内核态（kernel mode）和用户态（user mode）。为什么会这样设计？因为要防止一个程序把整个系统搞崩。

发行版：内核 + 一堆软件的打包

既然内核只有一个，为什么会有 Ubuntu、CentOS、RedHat 这么多「Linux」？

因为内核只提供最底层的功能，你还需要桌面、包管理器、常用工具，把它们和内核打包在一起，就叫发行版（Distribution）。内核是同一个，打包的内容不同。

发行版 包管理 特点
Ubuntu DEB（apt） 上手最容易，桌面和服务器都常用
RedHat / CentOS RPM（yum） 企业级，服务器市场占大头
Debian DEB（apt） 稳定保守，Ubuntu 就是从它衍生出来的
Fedora RPM（dnf） 偏新、偏激进，RedHat 的试验田
openSUSE RPM（zypper） 欧洲企业常用
Arch / Solus pacman / eopkg 滚动更新，适合折腾党

⚠️ 包管理器只有两个家族：DEB 系（apt） 和 RPM 系（yum / dnf）。被问到「CentOS 怎么装软件」，答案就是 yum install；换成 Ubuntu，则是 apt install。

终端与命令提示符

Linux 没有图形界面也能用，靠的是终端（Terminal），一个只能打字的黑框。你在里面输入命令，Shell 负责读懂并交给内核执行。

这一行把四件事都说清楚了。

部分 含义 说明
alex 当前用户 你以谁的身份在操作
@ 分隔符 固定写法
hadoop100 主机名 hostname，集群里靠它区分机器
~ 当前目录 ~ 代表当前用户的家目录；/ 才是根目录
$ 权限提示 $ 普通用户，# 超级用户 root。看到 # 就要小心了

Linux 的目录结构：一棵树，没有 C 盘

Windows 有 C 盘、D 盘，Linux 没有盘符，只有一棵树，最顶上是根目录 /。

⚠️ /tmp 和 /usr/tmp 是两个不同的目录，别混。前者是系统临时目录，后者是用户级的。

路径：绝对路径 vs 相对路径

  • 绝对路径 （absolute path）：从 / 写起，如 /home/alex/doc，在哪执行都一样；
  • 相对路径 （relative path）：从当前位置写起，如 doc、../doc；
  • . 当前目录，.. 上一级目录，~ 家目录，- 上一次所在的目录。

命令按用途分四组

1) 查看信息

2) 目录操作

3) 文件操作

最危险的一条命令

rm -rf / 会从根目录开始删除整个系统。Linux 没有回收站，删了就没了，执行前也不会有任何「你确定吗」的二次确认。
所以平时养成习惯：删之前先 ls 看一眼，把 rm -rf 当成手术刀用。

4) 用户与权限

用 ls -l 看到的第一列，长这样。

九个字符分三组，每组三位，分别对应 r（读 4）、w（写 2）、x（执行 1）。所以 755 = 属主 rwx，其他人 r-x。首字符表示类型。

首字符 File Type 说明
d Directory 目录
- File / Executable File 普通文件（有没有 x 决定能不能执行）
l Symbolic Link File 符号链接，相当于快捷方式
p Named Pipe (FIFO) 命名管道，进程间通信
s Socket 套接字
b Block Device 块设备，如硬盘
c Character Device 字符设备，如键盘
? Missing File 文件已丢失（链接悬空）

vim：Linux 下最常用的编辑器

第一次用 vim 的人都会懵：怎么打字打不进去？

因为 vim 有模式。打开时你在命令模式（Command Mode），按键被当成命令而不是文字。要打字，先按 i 进入插入模式（Insert Mode）。

命令模式Command — i / a / o → 插入模式Insert — Esc → 命令模式 — : → 末行模式Last-line

操作 按键
进入插入模式 i 光标前插入 / a 光标后插入 / o 下一行新开一行
回到命令模式 Esc
保存并退出 :wq（write & quit）
不保存强退 :q!
只保存不退出 :w

⚠️ 忘了按 Esc 就敲 :wq，这四个字符会原样插进正文，文件并没有保存。

七条能省下大量时间的技巧

  1. Tab 补全：命令、路径打一半按 Tab，自动补全，还能顺便检查你路径有没有打错；
  2. 上下方向键：翻历史命令，重复执行不用重打；
  3. Ctrl + C：强制中断当前命令（死循环、卡住的进程都靠它）；
  4. Ctrl + L：清屏（等同 clear）；
  5. **man 命令名**：查手册，如 man ls；不记得命令名就用 man -k 关键词；
  6. **命令 --help**：快速看用法，比 man 轻量；
  7. **history**：列出所有敲过的命令，配合 !编号 重跑。

一个习惯，能救很多次命

执行 rm、mv、chmod -R 这类命令前，先把同样的路径喂给 ls 看一眼。确认是你要动的那个目录，再执行。多花三秒，少哭一晚。

总结

  1. Linux 是操作系统，由内核（kernel）+ 系统程序 + 应用组成；内核管资源，用户态不能直接碰。
  2. 发行版 = 内核 + 一堆软件；包管理分两族：DEB（apt） 与 RPM（yum/dnf）。
  3. 提示符 [用户@主机目录]$，$ 普通用户、# root。
  4. 没有盘符，只有一棵从 / 开始的树；/bin 命令、/etc 配置、/home 家目录、/var 日志。
  5. 命令四组：查看信息、目录、文件、用户与权限。
  6. 权限 r=4 w=2 x=1，755=rwxr-xr-x；首字符 d/-/l 等表示类型。
  7. vim 三模式：命令 → 插入（i）→ 末行（:wq）；没有回收站，rm -rf 慎用。

2.2　为什么大数据要用 Python？

处理数据，Java、C++ 不是更快吗？为什么偏偏用 Python？

因为写 Python 的时候，你的时间花在想逻辑上，不是花在写细节上。有一句话点得很准：Python programmers can spend more time thinking about the program logic than the specific implementation details.

而且大数据生态里几乎所有工具都给了 Python 接口：Spark 有 PySpark，Hadoop 能写 Streaming，NumPy、pandas、matplotlib 直接把数据处理做成了几行代码。所以这门课把它当成默认的动手语言。

它是怎么来的

作者是荷兰人 Guido van Rossum（吉多·范罗苏姆）。1982 年他在阿姆斯特丹大学拿到数学与计算机的硕士学位，1989 年一个人把 Python 写了出来。

后来他和同事组成了 Python 的核心团队，语言一路演进：先是框架立住，然后标准库体系稳定，接着生态开始向第三方包扩张，Django、web.py、wxpython、NumPy、matplotlib、PIL，把 Python 从一门语言养成了「物种丰富的热带雨林」。

现在它的地位：Google 的第三大开发语言、Dropbox 的基础语言、豆瓣的服务器语言。

优点：为什么它好上手

优点 具体指什么
语法优雅、可读性高 读一段好的 Python 程序，像读英文
容易学 虽然底层用 C 写，但抛掉了 C 里最复杂的指针，语法大幅简化
自带庞大标准库 连 Web 服务器、正则匹配、文件读写这些常见任务都有现成的
交互模式 随手敲几行就能验证想法，试错成本极低
易扩展 可以用 C / C++ 写模块嵌进来，性能瓶颈交给它们
跨平台 macOS、Windows、Linux、Unix 都能跑
数据类型丰富 数字（浮点、复数、无限长整数）、字符串（ASCII / Unicode）、列表、字典
面向对象 支持类与多重继承
强类型 + 动态类型 类型不兼容会直接抛异常，错误暴露得早
自动内存管理 不用手动 malloc / free，垃圾回收自己处理

「强类型 + 动态类型」这两个词放一起，是不是有点矛盾？

不矛盾，它们是两件不同的事。

  • 强类型 （strongly typed）说的是「不会偷偷帮你转换」："1" + 1 直接报错，不猜你想干嘛；
  • 动态类型 （dynamically typed）说的是「类型在运行时才确定」：变量不用声明类型，赋什么就是什么。

有一句话说得很到位：In Python, you never declare anything. If a name is assigned to an object of one type, it may later be assigned to an object of a different type.

缺点：它不完美

缺点 怎么回事 / 怎么绕
很多语句写不进一行 表达力上不如某些函数式语言紧凑；Python 的做法是「宁可多一行，也要读得懂」
运行速度慢 关键部分用 C / C++ 重写；但对使用者而言，很多场景下这点差异根本感知不到
开源导致无法加密 源码就是明文，做商业闭源分发要另外想办法（编译、加壳）
Python 2 vs Python 3 两个版本不兼容，历史包袱重，新项目一律用 3

⚠️ 关于「慢」，Python 慢是事实，但大数据场景的瓶颈通常在 IO 和集群，不在解释器那几毫秒。

代码风格：几个不能马虎的细节

Python 有个著名的设计哲学，写在 The Zen of Python 里。

**Beautiful is better than ugly.**（优美胜于丑陋）
**Explicit is better than implicit.**（明了胜于晦涩）
**Simple is better than complex.**（简单胜于复杂）

规则 说明
大小写敏感 Name 和 name 是两个东西
没有大括号 也几乎没有分号；代码块靠缩进划分
缩进有意义 官方风格是每级 4 个空格；缩进错了程序直接跑不了
单双引号等价 但同一个项目里别混用
注释 # 单行注释；多行用文档字符串 '''…''' 或 """…"""（docstring）
命名 变量名不能以数字开头，不能用关键字
多重赋值 a = b = c = 1 一行搞定
风格指南 PEP 8（Style Guide for Python Code）：官方编码规范，全称很少写，通常只说 PEP 8

最该记牢的一句话

「Python 用缩进表示代码块，而不是大括号。」这一条决定了后面所有代码的样子。标准缩进量是 4 个空格，混用 Tab 和空格会报 IndentationError。

IDE：在哪写 Python

IDE（Integrated Development Environment，集成开发环境）就是「编辑器 + 运行 + 调试」打包在一起。学 Python 最省事的路子是装一个 Anaconda，它自带包管理器 conda、环境管理器，以及一大堆科学计算库，装环境这件事基本不用操心。

Anaconda Navigator 里能一键启动的工具，主要是这几个。

工具 适合干什么
JupyterLab / Jupyter Notebook 浏览器里的交互式笔记本，边写边看结果，做数据分析首选
Spyder 科学计算向的 IDE，变量查看器好用，像 MATLAB
Qt Console 轻量交互终端，画图直接嵌在窗口里
Glueviz / Orange 3 多维数据可视化、可视化编程做数据挖掘
RStudio R 语言的环境（顺便装着）
VS Code 通用编辑器，装 Python 插件后也是主力选择

基础语法：一小时能补完的部分

1) 基本运算与布尔

最后一行特别容易被忽略：布尔类型参与运算时会被当成 1 和 0，因为 Python 里 bool 是 int 的子类。

2) 四种容器（必须会用）

类型 符号 有序？ 可变？ 特点
list 列表 [] 有序 可变 元素类型可以不同，能增删改
tuple 元组 () 有序 不可变 初始化后不能改、不能追加，相当于「只读列表」
set 集合 {} 无序 可变 元素唯一，重复的自动去掉
dict 字典 {key: value} 有序（3.7+） 可变 键值对，key 唯一

列表推导式（list comprehension）的写法是 表达式 for 变量 in 迭代器 if 条件，一行完成「筛选 + 变换」，比写循环干净得多。

3) 控制语句

⚠️ for 循环里变量会被依次赋值为可迭代对象的下一个元素；可迭代对象可以是字符串、列表、元组、字典、集合。循环体必须缩进，否则不在循环里。这就是「缩进即语法」的直观体现。

4) 函数与 range

range 是左闭右开（*[start, stop)*），包含 start，不包含 stop。这个边界最容易记错，记不住就想 range(5) 是 0 到 4，不是 0 到 5。

5) 文件读写

用 with 的好处是块结束时自动关闭文件，不用自己写 close()，也不怕中途抛异常漏掉关闭。处理大文件时逐行读（像上面那样 for line in f），不要一次 read() 进内存。

遇到不会的，怎么查

五条途径，按「离线能用」排序，前三条平时就够用了。

  1. Python Manuals：安装时自带的官方文档；
  2. python.org/doc：官方在线文档；
  3. **help() 和 dir()**：最实用的两个内置函数；
  4. 搜索引擎（配上错误信息一起搜）；
  5. Python Wiki 的 Beginner’s Guide 之类学习资源。

⚠️ help() 的输出是分页显示的，看完按 Q 退出，卡在帮助里出不来，就是这个原因。

总结

  1. 作者与出身：Guido van Rossum，荷兰人，1989 年独立开发。
  2. 优点：语法优雅可读、易学、标准库大、有交互模式、可扩展、跨平台、类型丰富、面向对象、强类型、自动内存管理。
  3. 缺点：语句难挤成一行、运行慢（可用 C/C++ 重写）、开源不可加密、Py2 与 Py3 不兼容。
  4. 风格：大小写敏感、无大括号、缩进 4 空格、# 注释 + docstring、PEP 8。
  5. 四种容器：list [] 可变有序、tuple () 不可变、set {} 无序去重、dict {k:v} 键唯一。
  6. 语法细节：// 整除、% 取余、** 幂；布尔参与运算为 1/0；range 左闭右开。
  7. 求助：help() / dir()，按 Q 退出。
