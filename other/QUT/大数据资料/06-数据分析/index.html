06 数据分析

qiuxz2026-11-162026-11-16

数据已经存好、洗干净了，为什么还不能说它有价值？

因为价值在从数据里抽出来的规律里。数据是原料，原料本身不产生判断。数据要变成知识，得先被存储、被管理，再被分析。三步里只有最后一步直接产出结论。

存储Store → 管理Manage → 分析Analyze → 知识 / 预测Insight

有三个词在工程里经常混着用：大数据（big data）、数据挖掘（data mining）、预测分析（predictive analytics）。混用的原因是三者的落点相同，都是为了从数据里得出「接下来会怎样」。但它们指的对象不同：大数据说的是数据的规模与形态，数据挖掘说的是从数据里找模式的方法，预测分析说的是这些模式拿来干什么。

四个学科交叉出来的东西

数据分析没有单一的理论来源，它是四门东西的交叉。四者是同一件事的四个视角，不是四个步骤。

领域 提供什么 在一次分析里落到哪
统计学
statistics		 分布、估计、显著性检验 判断一个规律是不是巧合
机器学习
machine learning		 从样本里自动拟合模型 预测没见过的样本
数据挖掘
data mining		 在大规模数据里找模式与关联 从海量数据里筛出候选规律
数据可视化
data visualization		 把数据画成图形 先让人看见形状，再决定算什么

一次完整的分析里，四者通常都要出场：先画图看形状，再用统计判断这个形状是不是偶然，再用模型把它拟合下来，最后用挖掘的方法在海量数据上找更多同类模式。顺序里第一步最容易跳过去，跳过去的代价最大。

总结

  1. 三步：存储、管理、分析。只有分析这一步直接产出判断。
  2. 三个名字：大数据说的是数据形态，数据挖掘说的是找模式的方法，预测分析说的是模式的用途。
  3. 四个学科：统计判断真伪，机器学习做预测，数据挖掘做筛选，可视化做入口与表达。

6.2　先画图，再算数

四组数据的均值、方差、相关系数、回归直线全都一样，它们是同一组数据吗？

不是。1973 年统计学家 F. J. Anscombe 造了四组数据来回答这个问题，四组数据的数字摘要一模一样，画出来却是四种完全不同的形状。

摘要 四组共同的值
x 的均值 9.00
y 的均值 7.50
x 的方差 11.00
y 的方差 4.12
相关系数 r 0.816
线性拟合 y = 3 + 0.5x

换成散点图，四组的样子差得很远。

组 形状 哪里不一样
I 近似一条直线的趋势 点沿着直线散开，有正常的随机抖动
II 明显的弧线 关系不是直线的，用直线拟合本身就选错了模型
III 一条笔直的线，加一个离群点 直线是被那个远离大部队的点「抬」出来的
IV 所有 x 都等于 8 只有一个 x = 19 的点撑起了整条回归线的斜率

这就是安斯库姆四重奏（Anscombe’s Quartet）要说的事：数字摘要会把数据的形状抹平。均值与方差只描述「中心在哪、散得多开」，不描述「怎么散」。不描述形状，就可能对一条弧线做直线拟合，也可能为 IV 那种「所有点 x 相同」的数据算出一个漂亮的相关系数。

四组数据的均值、方差、相关系数、回归线几乎完全相同，散点形状差了十万八千里。

所以分析的第一步是画图。看完形状再决定用什么方法，这个顺序不能反。

可视化到底在做什么

数据可视化（data visualization）用图形手段呈现数据，把数据里的信息清楚有效地传达出去，帮人看出数据中包含的规律与现象。也就是用数据讲故事（telling the story with data）。

优势 说明
看见统计看不见的结构 数据结构与细节，统计量描述不出来
门槛低 解读图形对读者的知识水平要求低，不必先懂统计
效率高 提高人理解与处理数据的效率

第三条是可视化真正的价值所在。它是分析的入口，不是给结论配一张好看的图。图上看不出来的东西，后面的模型也很可能抓不到。

摘要与形状

① 均值、方差、相关系数、回归线全相同，四组数据的形状可以完全不同；
② 数字摘要描述的是「中心与离散」，不描述「形状」；
③ 画图是分析的入口，不是结论的装饰。

总结

  1. 安斯库姆四重奏：四组数据摘要相同（均值 9 / 7.5，方差 11 / 4.12，r = 0.816，y = 3 + 0.5x），形状分别是线性、弧线、直线加离群点、单点撑斜率。
  2. 结论：数字摘要抹平形状，形状只能靠图看出来。
  3. 可视化三条优势：看见统计看不见的结构、解读门槛低、提高理解与处理效率。
  4. 定位：可视化是分析的第一步，不是最后一步的装饰。

6.3　四种数据尺度，八种统计图

同样一列数，为什么有的能算平均值，有的不能？

因为数据的尺度（scale）不同。尺度决定两件事：能做什么运算，能画什么图。四种尺度是按「能做的运算越来越多」排下来的。

尺度 特点 例子 能做的运算
定类
Nominal		 只是名字，没有大小与顺序 颜色、民族、城市 只能数频数，判断相等与不等
定序
Ordinal		 有顺序，但相邻间隔不等距 满意度（很满意 / 一般 / 不满意）、学历 能比大小，不能做加减
定距
Interval		 间隔等距，零点是人定的 摄氏温度、年份 能加减，不能乘除
定比
Ratio		 有绝对零点 身高、体重、收入、销量 四则运算都能做

关键差别在「零点是不是自然的」。摄氏 20 度不是 10 度的两倍，因为 0 度是人定的一条线；身高 180 cm 是 90 cm 的两倍，因为 0 cm 意味着「一点长度都没有」。定距与定比的分界就是零点。

这条界线直接管着后面所有计算：定类、定序数据不能求均值，「颜色的平均值」「满意度的平均值」都是没有意义的量。

八种统计图，各管一件事

图 表达什么 数据要求
柱状图
bar chart		 离散数据之间比大小 离散
直方图
histogram		 离散类型的频数分布 离散，连续值要先分箱
折线图
line chart		 趋势 有一个有序的维度（时间最常见）
饼图
pie chart		 占比，尤其是「部分对整体」的关系 各部分加起来等于一个整体
散点图
scatter diagram		 数据的分布与两个变量之间的关系 两个连续变量
热力图
heat map		 多个特征之间的关系 两个离散维度 + 一个数值
箱线图
box plot		 取值的分布范围（中位数、四分位、离群点） 一个离散维度分组 + 一个连续值
雷达图
radar chart		 若干个不同特征、能力的分布对比 几项可比的指标

饼图有一条硬限制：所有部分必须构成一个整体。拿两个饼图去比较两组样本，两个圆一样大，读者会以为样本量相同；两个圆不一样大，又没法比占比。饼图只适合展示一个整体的内部构成，不适合做组间比较。

八种图各自回答一个问题：比大小、看分布、看趋势、看占比、看关系、看相关、看离散、看多维。

两个变量怎么配图

画图前先看两个变量各是什么尺度，组合只有三种。

组合 用哪些图 例子
离散 × 离散 热力图、直方图 性别 × 是否购买
离散 × 连续 箱线图、柱状图 学历 × 收入
连续 × 连续 散点图、热力图、核密度估计 身高 × 体重

连续 × 连续这一格多出一个 核密度估计（kernel density estimation，KDE）。它不画每个点，画的是点在平面上的「密度」。

做法是给每个数据点套一个核函数（常用高斯核），在这个点周围铺一个平滑的包，再把所有的包叠起来，最后归一化，让整体面积为 1。过程里没有对分布形状作任何假设。

好处正是这一点：分布形状未知时照样能画。代价有两个，一是数据量大时计算量跟着涨，二是数据噪声大时包会叠成一团，出现过平滑（oversmoothing），把本来分开的两个峰抹成一个。

选图之前先问三句

问什么 可选值
目的 比较、趋势、组成、联系、分布
变量类型 数值、日期、类别、经纬度
维度 分布、趋势

三句答完，图基本就定了。反过来先挑图再想表达什么，得到的多半是一张好看但说不了事的图。

总结

  1. 四种尺度：定类（只数频数）、定序（能比大小）、定距（能加减，零点人为）、定比（四则运算，零点自然）。
  2. 界线：零点是否自然，把定距与定比分开；尺度决定能不能求均值。
  3. 八种图：柱状、直方、折线、饼、散点、热力、箱线、雷达。
  4. 三种组合：离散 × 离散用热力图与直方图；离散 × 连续用箱线图与柱状图；连续 × 连续用散点图、热力图、KDE。
  5. KDE：不假设分布形状，代价是计算量与过平滑。
  6. 选图三问：目的、变量类型、维度。

6.4　Matplotlib：先认清画布上的九个部件

一行 plt.plot() 就能出图，为什么还要知道 Figure 和 Axes？

因为要改图的时候，改的永远是某个部件。不知道一张图由哪些部件组成，就只能一遍遍试参数。

部件 中文 管什么
Figure 画布 整张图，可以包含多个坐标系
Axes 坐标系 真正画图的那块区域，一张图上可以有多个
Axis 坐标轴 x 轴与 y 轴本身
Spines 边框线 坐标系四周的框线
Ticks 刻度 刻度线与刻度值
Label 标签 轴名、刻度名
Grid 网格线 背景辅助线
Legend 图例 哪条线、哪个颜色代表什么
Title 标题 图的标题

九个部件里最容易混的是 Figure 与 Axes。Figure 是纸，Axes 是纸上画图的框。 一张 Figure 可以放好几个 Axes，子图（subplot）就是这么来的。

改图就是改这里的某一块：调 ax.set_title() 动的是 ③，调 ax.legend() 动的是 ⑦，调 ax.grid() 动的是 ⑧。

一次出图的固定顺序

顺序不是随意的：画布先建，图画在画布上，图例、刻度、网格都是对已有图的修饰，保存与显示放最后。七步里有五步是修饰，真正画数据的只有第二步。

工具生态

类别 工具 定位
Python 系 matplotlib 最底层，什么都能画，代码最啰嗦
seaborn 建在 matplotlib 上，统计图更省事
pyecharts 生成可交互的网页图表
JavaScript 系 ECharts 网页端图表库，配置化，文档全
D3 底层绘图，自由度最高
Processing.js 偏创意与动画
在线平台 Plotly、Kibana 不装环境，直接在网页上画；Kibana 偏日志与监控
应用软件 Tableau 拖拽式，不写代码

选哪一类看交付形态：要嵌进网页、要能交互，走 JavaScript 系；要做分析、要批量出图，走 Python 系；要给不写代码的人用，走应用软件。三类的差别在画完放在哪。

总结

  1. 九个部件：Figure 画布、Axes 坐标系、Axis 坐标轴、Spines 边框、Ticks 刻度、Label 标签、Grid 网格、Legend 图例、Title 标题。
  2. Figure 与 Axes：纸与纸上的框，一张 Figure 可以有多个 Axes。
  3. 出图顺序：建画布、画、加图例刻度网格、保存、显示。
  4. 三类工具：Python 系（matplotlib / seaborn / pyecharts）、JavaScript 系（ECharts / D3 / Processing.js）、在线平台与 Tableau。

6.5　机器学习：程序怎么「学」

一段写死的程序，凭什么说自己学会了东西？

Tom Mitchell 给了一个可检验的定义：如果一个程序在任务 T 上的表现 P，随着经验 E 提高，就说它从 E 中学到了东西。（*A computer program is said to learn from experience E with respect to some class of tasks T and performance measure P, if its performance at tasks in T, as measured by P, improves with experience E.*）

定义里只有三个字母，缺一不可：有明确的任务 T，有能算出来的评价标准 P，有可积累的经验 E。三者不齐，就不是机器学习，只是写死的一堆规则。

字母 是什么 在垃圾邮件分类器里
T 任务 判断一封邮件是不是垃圾邮件
P 表现度量 判对的邮件占全部邮件的比例
E 经验 已经标好的历史邮件

什么样的模式才值得叫模型

不是所有规律都值得做成模型。四条要求，一条都不能少。

要求 意思
有效
valid		 在新数据上仍然成立，有一定把握。不只是记住了训练集
有用
useful		 能据它采取行动，光知道没用
意外
unexpected		 不显而易见，也没法用现成的数学式子写出来
可理解
understandable		 人能解释这个模式为什么成立

四条里最容易被忽略的是第三条。用一条已知公式拟合出来的关系不叫发现，真正的模型要给出一个原本没写在公式里的结论。第一条则是后面所有评估方法的出发点：模型的价值在没见过的数据上，不在训练集上。

一次建模的五个动作

探索目标变量 → 切分训练 / 测试 → 建模 → 模型评估 → 优化 → 预测

顺序里有两个要紧的地方。切分必须在建模之前，否则测试集就不再是「没见过的数据」；评估之后还要回到建模那一步调，五个动作是一个环，不是一条直线，最后一轮评估满意了才拿去预测。

四种学习范式

范式 数据有什么 学什么
监督学习
supervised		 训练数据带已知标签或结果，如垃圾 / 非垃圾、某时刻的股价 从输入到标签的映射
无监督学习
unsupervised		 输入没有标签，也没有已知结果 数据自身的内在结构
半监督学习
semi-supervised		 一部分有标签，一部分没有，混在一起 用少量标签带动大量无标签数据
强化学习
reinforcement		 没有标签，只有动作之后拿到的奖励 什么样的动作序列回报最大

算法地图：两个问题定位

算法很多，选哪个由两个问题定：有没有标签，要预测的是连续值还是离散值。两问交叉出四格。

连续属性 离散属性
监督 回归：线性回归、kNN、决策树 分类：逻辑回归、SVM、朴素贝叶斯、kNN、决策树
无监督 降维：PCA 聚类：k-Means
关联规则：Apriori

kNN 和决策树在两格里都出现，原因是它们两件事都能做：kNN 让邻居投票就是分类，取邻居均值就是回归；决策树的叶子放多数类就是分类树，放均值就是回归树。CART 名字里的 R 就来自 regression。

九族常用算法

族 代表算法
回归 regression 线性回归、岭回归 Ridge、LASSO
基于实例 instance-based kNN、SVM
决策树 decision tree CART、ID3、C4.5、C5.0
贝叶斯 bayesian 朴素贝叶斯、高斯朴素贝叶斯
聚类 clustering k-Means、层次聚类
关联规则 association rule Apriori、FP-Growth
神经网络 neural network BP、CNN、RNN
降维 dimensionality reduction PCA、LDA
其他 others 集成算法、特征选择算法

这张表里有两处要分清。聚类与关联规则没有标签，属于无监督；PCA 与 LDA 都做降维，但 PCA 不看标签、LDA 用标签，所以前者算无监督、后者常算作监督式降维。另外集成算法不引入新模型，它把已有的模型组合起来，后面随机森林就属于这一类。

机器学习的定义

① 机器学习 = 任务 T + 表现 P + 经验 E，缺一个都不算；
② 好模型要有效、有用、意外、可理解，其中「有效」指在没见过的数据上成立；
③ 选算法先问有没有标签，再问输出是连续还是离散。

总结

  1. Mitchell 定义：任务 T、表现度量 P、经验 E，三件齐了才叫学习。
  2. 四条要求：有效、有用、意外、可理解。
  3. 五个动作：探索目标变量、切分训练测试、建模、评估、优化，最后才预测；这是一个环。
  4. 四种范式：监督、无监督、半监督、强化。
  5. 四格地图：监督 × 连续 = 回归，监督 × 离散 = 分类，无监督 × 连续 = 降维，无监督 × 离散 = 聚类与关联规则。

6.6　回归：一条线，两种求法

一堆散点，凭什么说某一条直线就是「最合适」的？

「最合适」得先定义。回归要解决的是连续值的预测，线性回归（linear regression） 假设输出是输入的线性组合：y = w·x + b。剩下的事是定 w 和 b，而定的办法有两种经典思路。

两种思路，同一个解

最小二乘（least squares）从误差出发：选一组参数，让观测值与估计值之间的误差平方和最小。平方有两个作用，一是让正负误差不互相抵消，二是让大误差受更重的罚。

最大似然（maximum likelihood）从另一个角度出发：把数据看成从某个模型里抽出来的样本，选一组参数，让「抽出这 n 个样本」这件事的概率最大。

两条路的思路毫不相干，结论却一致：在误差服从正态分布的前提下，两者解出同一组参数。「误差最小」和「最可能产生这份数据」在正态误差的条件下是同一件事。 这也是线性回归在回归问题里地位稳固的原因。

拟合得太好也是病

同一批数据，分别用 1 次、3 次、9 次多项式拟合。次数越高，曲线越贴合每个训练点，也越偏离灰色的真实规律。

参数越多，模型在训练集上的误差一定越小，可以小到 0。但训练误差趋近 0 的模型，换一份数据往往错得离谱。这叫过拟合（overfitting）：模型把训练数据里的噪声也当成了规律。

这里的问题在于怎么在「拟合得够准」与「别太复杂」之间划线。有一条老原则叫 奥卡姆剃刀（Occam’s razor）：在所有能很好解释已知数据的模型里，选最简单的那一个。复杂度用分裂次数、参数个数这类量来计，越简单越不容易过拟合。

把「简单」写成公式：正则化

奥卡姆剃刀是句原则，要用得起来得写成可优化的目标。做法是在损失函数后面加一项惩罚（penalty）。

椭圆是损失函数的等高线，圆和菱形是惩罚项允许的范围，两者相切处就是解。L1 的菱形有尖角，切点容易落在角上，于是某个系数正好被压成 0。

目标函数objective = 损失函数loss + 惩罚项penalty

惩罚项取哪种范数，决定了模型会长成什么样。两种选择各对应一个有名字的方法。

惩罚 范数怎么算 方法 效果
L1 向量各元素绝对值之和，Σ|w| LASSO 部分系数被压到正好 0，顺手做完了变量选择
L2 各元素平方和再开方，√Σw² Ridge（岭回归） 系数整体被压小，但很少压到 0

LASSO 的全名说明了它的行为：least absolute shrinkage and selection operator，最小绝对值收敛和选择算子。这里的「选择」就是把没用的变量系数压成 0，把变量剔出去。Ridge 的名字里没有 selection，因为它只收敛、不选择。

⚠️ L1 会把系数压到 0，L2 只把系数压小。 几何上的原因在于惩罚区域的形状：L1 的等值线是菱形，顶点落在坐标轴上，最优点容易正好撞在轴上；L2 的等值线是圆，接触点大多在象限内部，坐标不会恰好为 0。

线性回归的边界

线性回归是最简单、最好用的回归模型，代价是那条规定：特征与目标之间必须是线性关系。现实中大多数数据并不严格线性，所以它的适用范围有限。但在完全不了解特征之间关系的时候，它仍然可以当基线（baseline）：先看一条直线能做到多好，再看更复杂的模型有没有必要。

总结

  1. 两种求法：最小二乘让误差平方和最小；最大似然让抽出这批样本的概率最大；正态误差下同解。
  2. 过拟合：训练误差一直降，换数据就崩；判据是复杂度而不是训练误差。
  3. 奥卡姆剃刀：能解释同一批数据时，选最简单的模型。
  4. 正则化：目标函数 = 损失 + 惩罚；L1 → LASSO（压到 0，会选变量），L2 → Ridge（压小，不归零）。
  5. 边界：线性假设限制了适用范围，但适合当基线。

6.7　分类：从概率到投票

要预测的是「是 / 否」，一条直线还够用吗？

不够。回归输出的是能取任意值的连续量，分类要输出的是类别。把回归的线硬切成两段也能分类，但输出值没有上下界，不能当概率用，所以得换一个函数。

逻辑回归：给线性输出套一个压缩函数

逻辑回归（logistic regression）是二分类问题的首选方法。名字来自它的核心函数，logistic 函数，也叫 sigmoid 函数：一条 S 形曲线，把任意实数压进 (0, 1) 区间。压进去之后，输出就可以当「属于正类的概率」用。

整个实数轴被压进 (0, 1)：z 再小也到不了 0 以下，再大也超不过 1。z = 0 时输出 0.5，正好是判正判负的分界。

名字里带 regression，做的却是分类。regression 指的是它内部先算了一个线性组合，不是它输出什么。

优点 缺点
计算代价低 容易欠拟合
容易理解、容易实现 分类准确率可能不高

kNN：不建模，直接看邻居

k 近邻（k-nearest neighbor）对新样本 x 的处理方式很直接：在整个训练集里找出与 x 最相似的 k 个实例，用这 k 个实例的输出决定 x 的输出。回归取这 k 个输出的均值，分类取这 k 个输出的众数。

它没有训练过程，所有计算都发生在预测的时候。这一点直接决定了它的优缺点。

同一批点，只换 k。k = 1 时边界要绕开每一个训练点，噪声也被当成规律；k = 15 时多数票把边界抹平，代价是细节被一起抹掉。

「最相似」怎么算

相似度由距离定义。三种常用距离是层层包含的关系，闵可夫斯基最一般，另外两个是它的特例。

这条式子对连续值好用，对另外三类数据就不合适，得换各自的算法。

非连续数据怎么量相异度

二元变量（dichotomous variable）只取 0 和 1，用来表示「有 / 无」。最直接的办法是数「同一位置上取值不同的位数占多少」，这叫对称二元相异度。

但有些场景下「两边都是 0」不该算相似。判断两个人是否患有同一种病，都患病说明相似，都不患病并不说明相似。这时分母要把「同取 0」的位数扣掉，得到非对称二元相异度；用 1 减掉它，得到 Jaccard 系数。

指标 式子
对称二元相异度 (b + c) / (a + b + c + d)
非对称二元相异度 (b + c) / (a + b + c)
Jaccard 系数（非对称相似度） a / (a + b + c)

a 是两边都取 1 的位数，b、c 是一边取 1 一边取 0 的位数，d 是两边都取 0 的位数。拿两个八位向量走一遍：

分母从 8 变成 6，就是那两个「同取 0」的位被扣掉了。

分类变量（categorical variable）是二元变量的推广，取值像枚举，之间没有大小与序数意义，比如颜色、民族。它的相异度用「取值不同的同位属性数 ÷ 单个元素的全部属性数」，回到对称的算法。

向量不一样：它既有大小又有方向。闵可夫斯基距离只看长度差，方向反了也可能算「近」。所以向量用余弦相似度（cosine similarity）比方向，不看长度。

决策树：把判断拆成一串问题

一棵决策树的结构很简单，只有两种角色。

顺着树往下走，每层回答一个问题，走到叶子就得到答案。问题在于「先问哪个变量、在哪里切」，这靠三个判据。

三种判据对应三个年代。ID3（Iterative Dichotomiser，迭代二分器）在 1970 年代后期到 1980 年代初由 J. Ross Quinlan 提出；他后来给了 ID3 的后继 C4.5，长期作为监督学习的性能基准；1984 年几位统计学家提出 CART。

树不能一直长下去，两个停止条件：所有数据在 y 上已经一致；或者所有特征都已经分裂过。光有停止条件还不够，防止过拟合还要剪枝（pruning）。树的复杂度定义成树里的分裂次数，越简单越不容易过拟合。

后剪枝

长处 代价

随机森林：让很多棵树投票

单棵树容易过拟合，把很多棵组合起来更稳。这类做法叫集成学习（ensemble learning），也叫多分类器系统（multi-classifier system）。随机森林（random forest）是其中最常用的一种。

「随机」有两处，一行一列：

方向 抽样方式 结果
行（样本） 有放回抽样 bootstrap 每棵树的训练集都不同，有重复样本，也有没被抽中的样本
列（特征） 无放回随机抽一个特征子集 每棵树只看一部分特征，树与树之间的差异被拉开

最后用多棵树投票决定类别。两处随机的作用都是让树之间不相似：如果每棵树都在同一批数据、同一批特征上长，它们会一起犯同一个错，投票就没有意义了。

三个分类器

① 逻辑回归做分类，核心是把线性输出压进 (0, 1) 的 sigmoid；
② kNN 不训练、只算距离，二元变量要区分对称与非对称，向量用余弦；
③ 决策树靠信息增益 / 增益率 / 基尼不纯度选分裂点，随机森林靠行抽样本、列抽特征把树拉开。

总结

  1. 逻辑回归：二分类首选；核心是 logistic / sigmoid 函数；代价低、易实现，但容易欠拟合。
  2. kNN：找 k 个最近邻，回归取均值、分类取众数；无训练、预测时算全部距离。
  3. 距离：闵可夫斯基最一般，曼哈顿 p = 1，欧氏 p = 2。
  4. 二元变量：对称相异度用全部位数做分母；非对称扣掉同取 0 的位数；1 减非对称相异度 = Jaccard 系数。
  5. 决策树：根 / 内部节点放变量与分裂点，叶节点放输出；判据 ID3（信息增益）、C4.5（增益率）、CART（基尼）；预剪枝与后剪枝防过拟合。
  6. 随机森林：行 bootstrap、列随机子集，多树投票；随机是为了让树不相似。

6.8　聚类：一个标签都没有，凭什么分组

没有任何标注，怎么知道这几条数据该算一类？

靠「近」。聚类（clustering）不给标签，只从输入本身找出簇结构：输入是一堆向量 xi，输出是每个向量的簇标签 z，簇的个数 k 由人给。

这句话里有个前提，「近」是定义出来的，不是发现的。换个距离定义，簇就换一批。所以聚类的结果没有绝对的对错，只有「按这个定义算不算分得好」。

簇长什么样

一个簇由两件事刻画：中心（center）和形状 / 分散度（shape / spread）。判断一个样本属于哪个簇，就是给它和每个簇打分，分高的赢。为了简单，打分通常直接定义成 「到簇中心的距离」，距离越近分越高。

k-Means 的四步

k-Means 的名字已经说明了打法：k 个簇，每个簇用均值（mean）代表。

① 初始化 k 个中心 → ② 分给最近的中心 → ③ 中心改成簇均值 → ④ 重复 ②③ 到收敛

它要做的事可以写成一句优化目标：用每个簇的均值代替簇内所有样本，让总误差最小。 第 ③ 步就是在执行这句话，第 ② 步是在给定中心时把误差压到最小。两步交替，整体误差只会降不会升，所以一定会收敛到一个稳定状态。

灰色虚线是这一步中心的移动方向。三步之后三个中心各落在一个簇的均值上，颜色不再变化。

三个毛病

问题 原因
k 要人给，不同 k 结果差很多 算法本身不决定簇数，簇数一换，「好」的标准也跟着换
只对球形簇效果好，非球形效果差 判据是到中心的距离，簇一弯，中心就落在簇外面了
对初始中心敏感，容易落进局部最优 几个初始中心靠得很近、甚至落在同一个簇里时，收敛到的结果必然偏离合理值

第三条是改进算法的主要着力点：让初始中心之间彼此远离。常见做法是先随机选第一个中心，之后每个新中心都选「离已有中心最远」的那个点，这样几个中心不会一开始就挤在同一堆数据里。

总结

  1. 定义：不给标签，从输入找出簇结构；输出簇标签 z，簇数 k 由人给。
  2. 簇：由中心与形状 / 分散度刻画；打分常用到中心的距离。
  3. 四步：初始化中心、分配到最近中心、中心改成簇均值、重复到收敛。
  4. 目标：用簇均值代替簇内样本时总误差最小。
  5. 三个毛病：k 靠人定、只擅长球形簇、对初始中心敏感易局部最优。

6.9　评估：怎么证明模型靠得住

训练集上 99% 都判对了，能说明这个模型好吗？

不能。模型见过那些数据，判对是应该的。要衡量的是泛化误差（generalization error），也就是模型在没见过的数据上会错多少。三类模型的指标各成一套。

模型 指标
回归 MSE、RMSE、相关系数 r、可决系数 R²
分类 混淆矩阵、Accuracy、Precision、Recall、F1、P-R 曲线、ROC / AUC
聚类 RI / ARI、轮廓系数、Calinski-Harabaz 指数

回归：误差多大，拟合多好

指标 定义 怎么读
MSE 均方误差 (1/n)Σ(yi − ŷi)² 越小越好，量纲是原量纲的平方
RMSE 均方根误差 √MSE 越小越好，量纲回到原量纲
协方差 covariance 两个变量一起偏离各自均值的平均 大于 0 正相关，小于 0 负相关，等于 0 无线性关系
相关系数 r Pearson 积矩相关系数 −1 ≤ r ≤ 1，绝对值越大关系越强
可决系数 R² 被模型解释的方差占总方差的比例 0 ≤ R² ≤ 1，越大越好

这几个数里有两条关系要理清。

一是协方差与相关系数。协方差为 0 只说明没有线性关系，不代表两个变量没关系：沿一条抛物线对称取点，协方差接近 0，关系却很明确。相关系数是协方差除掉两边标准差之后的版本，好处是不受量纲影响，能跨数据集比较。

二是 R² 与 r。一元线性回归下 R² = r²，只有一维特征时两条式子等价；特征多于一个时这个等式不再成立，R² 仍然有效，r 就没有定义了。

指标是分层的。第一层是这四个计数，第二层是比出来的比例，第三层再把比例合成一个数。

第二层指标 式子 回答什么问题

Specificity 特异度 TN / (TN + FP) 真正的负例里，排除了多少

查准率与查全率是一对矛盾：想把正例都抓出来（提高 recall）就得放宽判据，误报 FP 跟着涨，precision 跟着掉；想判得准（提高 precision）就得收紧判据，漏掉的 FN 变多，recall 跟着掉。两个都想高，只能靠换更强的模型，调阈值只是在两者之间挪位置。

所以先要确定哪一头是硬约束。

场景 硬约束 为什么
搜索结果、语法纠错 保 precision 不能容忍 FP：搜出来一堆不相关的，工具就没人用了
医学诊断 保 recall 不能容忍 FN：漏掉一个病人，代价远大于多查一次

两头都要的时候，用一个数把两者合起来。F1 分数取查准率与查全率的调和平均：

为什么用调和平均不用算术平均：算术平均下 P = 1、R = 0 还能得 0.5，可这个模型一个正例都没抓到，毫无用处；调和平均会被小的一方拉到底。所以 F1 只在两者都不低时才高，取值 1 最好、0 最差。

拿十个样本算一遍，模型的预测和真实标签对比如下。

计数 值 是哪几位
TP 3 第 7、8、9 位：真实 P，预测 P
FP 1 第 4 位：真实 N，预测 P（误报）
TN 4 第 1、2、5、6 位：真实 N，预测 N
FN 2 第 3、10 位：真实 P，预测 N（漏报）

P = 3/4 = 0.75，R = 3/5 = 0.60，F1 = 2 × 0.75 × 0.60 / 1.35 = 0.667。另外 Accuracy = (3 + 4) / 10 = 0.70。accuracy 看着比 F1 高，因为它把 TN 也算进去了：正例只占一半时，把 4 个真负例判对就能撑起不小的准确率。

阈值一动，两个数一起动

分类模型输出的通常是一个小数，相当于置信度，不是 0 或 1。设一个阈值 T，大于等于 T 判正例、小于 T 判负例。T 一变，TP / FP / FN / TN 全变，precision 与 recall 也跟着全变。

阈值从 0 移到 1：查全率单调下降，查准率单调上升，F1 在中间某处最高。调阈值就是在调这个平衡。

把每个样本的取值都当一次阈值，每次算一对 (precision, recall)，在平面上连起来就是 P-R 曲线。比较两条曲线的优劣有三条规则：

  1. 一条完全包住另一条，外层的更好；
  2. 发生交叉时，比曲线下方的面积，面积大的更好；
  3. 或者比平衡点 BEP （break-even point），也就是 P = R 那个位置的取值，越大越好。

ROC 曲线（receiver operating characteristic curve）换了一对坐标：纵轴是真正例率 TPR（就是 recall），横轴是假正例率 FPR（= FP / (FP + TN) = 1 − specificity）。曲线越靠左上角，模型越好；贴着对角线，说明模型的判断与随机猜差不多。

两条 ROC 交叉时也不好比，于是取曲线下的面积，叫 AUC（area under curve）。AUC 的取值在 0.5 到 1 之间，随机猜是 0.5，越大越好。它比曲线好用的地方在于：它是一个数，不用看图比。

曲线越靠左上角越好。对角线是随机猜，AUC = 0.5；完美点是左上角的 (0, 1)。

聚类：没有标签怎么评

聚类没有标准答案，所以评估方法分两路：有外部标准时用外部法，没有时用内部法。

路线 判据 代表指标
外部法
external		 聚类结果与真实类别分布的一致程度 RI、ARI
内部法
internal		 簇之间的分离度（separation）与簇内部的紧凑度（cohesion） 轮廓系数、CH 指数

RI（Rand index，兰德系数）统计两类元素对：在聚类结果里同类、在真实类别里也同类的对，加上两边都不同类的对，占全部可组成元素对的比例。取值 0 到 1，聚类结果与真实划分完全一致时为 1。它的问题在于随机聚类的 RI 并不接近 0，所以又提出调整兰德系数 ARI（adjusted Rand index），让随机结果接近 0，区分度更高。

轮廓系数（silhouette coefficient）对第 i 个对象算两个量。

量 怎么算
ai i 到同簇其他所有对象的平均距离，越小说明簇越紧凑
bi i 到最近的那个其他簇中所有对象的平均距离，取所有其他簇里的最小值，越大说明离别的簇越远

接近 1 说明簇内紧、离别的簇远；接近 0 说明它正好卡在两簇边界上；负值说明它被分到了比「本该在的簇」更远的簇里，多半是分错了。

CH 指数（Calinski-Harabaz index）用比值，簇间离散度除以簇内离散度。

分子大说明簇分得开，分母小说明簇内聚得紧，所以CH 越大越好。它和轮廓系数常配着用：轮廓系数看单个样本落在什么位置，CH 看整体分得好不好。

三把评估尺子

① 回归看误差（MSE / RMSE）与拟合优度（r、R²），一元线性回归下 R² = r²；
② 分类先数 TP / FP / TN / FN，再算 precision / recall，最后合成 F1；
③ 聚类分外部法与内部法，内部法看分离度与紧凑度之比。

总结

  1. 评估对象：泛化误差，不是训练误差。
  2. 回归指标：MSE、RMSE（越小越好）；协方差（符号看方向）；r（−1 到 1）；R²（0 到 1，越大越好，一元下 = r²）。
  3. 混淆矩阵：TP 真正例、FP 假正例（误报，Type I）、TN 真负例、FN 假负例（漏报，Type II）。
  4. 第二层：Accuracy = (TP+TN)/全部；Precision = TP/(TP+FP)；Recall = TP/(TP+FN)；Specificity = TN/(TN+FP)。
  5. 取舍：precision 与 recall 相互矛盾；搜索、纠错保 precision，医学诊断保 recall。
  6. F1：2PR/(P+R)，调和平均，1 最好 0 最差。
  7. 曲线：P-R 看包住 / 面积 / BEP；ROC 以 TPR 对 FPR，越靠左上越好，AUC 0.5 到 1，越大越好。
  8. 聚类：外部法 RI、ARI；内部法轮廓系数（−1 到 1，=(b−a)/max(a,b)）与 CH 指数（越大越好）。

6.10　调参：哪些数能算，哪些数得定

模型里的数，哪些能从数据里算出来，哪些必须人来指定？

这正是参数（parameter）与超参数（hyperparameter）的分界。

类型 定义 例子
参数 模型内部的量，可以用数据估计出来 线性回归的 w 与 b、逻辑回归的系数
超参数 模型外部的配置，值没法从数据估出来 正则化系数；kNN、k-Means 的 k；决策树的 max_depth、min_samples_split

差别在于「能不能被优化目标唯一确定」。参数是优化过程的产物，超参数是优化开始之前就定下的配置，所以要另想办法挑。

两种搜索办法

网格搜索（grid search）把每个超参数的候选值列出来做笛卡尔积，每种组合都试一遍，取最好的一组。稳，但组合数随参数个数指数增长。

随机搜索（random search）在取值范围内随机采样若干组。它常常更快找到好结果，原因是通常只有少数几个超参数真正影响结果，网格搜索会在不重要的维度上浪费掉大量组合。

拿什么数据挑超参数

不能用测试集挑。测试集一旦参与过选择，它就不再代表「没见过的数据」，评估结果会虚高。常规做法是交叉验证。K 折交叉验证（K-fold cross validation）的步骤：

  1. 把数据集切成 K 份（折，fold），每份大小相近；
  2. 拿第 1 折当测试集，其余各折合起来当训练集；
  3. 算出这次的测试准确率；
  4. 换一折当测试集，重复第 2、3 步，一共 K 次；
  5. 把 K 次的准确率取平均，作为泛化准确率的估计。

K 次训练里，每一折都当过测试集，所有数据都被用到，也没有任何一条数据在同一轮里既训练又测试。代价是要训练 K 次，K 常取 5 或 10；再往大，收益不明显而计算量继续涨。

总结

  1. 参数 vs 超参数：参数能用数据估计（w、b、系数）；超参数不能（正则化系数、k、max_depth、min_samples_split）。
  2. 搜索：网格搜索做笛卡尔积，稳但组合爆炸；随机搜索采样，常常更快。
  3. 选超参数不能碰测试集，否则评估虚高。
  4. K 折：切 K 折、轮流做测试集、K 次取平均；代价是训练 K 次。

手上只有一百条记录、三个字段，画几张图能得出什么结论？

6.12　机器学习实操：三个回归模型走完一遍

同一份数据，怎么用一条直线把分数算出来，又怎么知道算得准不准？

6.5 节讲过建模的五个动作，6.6 节讲过线性回归与它的两个变体。这一节把两样东西合起来用：在 6.11 那份成绩表上，用三个模型各跑一遍，比完再拿最差的那个去调参。代码用 scikit-learn（sklearn），装法见 2.2 节。

前四步每轮都要跑，最后一步只在评估不满意时才走，走完回到拟合。

第一步：把特征和目标分开

特征就是 6.11 造出来的那两列。hours 是取整后的小时数，带四位小数的 time_study 已经在画热图那一步删掉了。用取整值训练，模型学到的规律就是”每天学几小时”，与 6.11 那几张图看的是同一个量。

data[['number_courses', 'hours']] 用了两层方括号，拿到的是一个两列的表格；只写一层 data['Marks'] 拿到的是单列。模型的输入必须是表格，所以特征那一侧要两层，目标那一侧一层就够。

特征记作 X、目标记作 y，这只是一套习惯写法。监督学习（supervised learning）要的就是这一对：每个样本既有输入，也有标准答案。

第二步：划分训练集和测试集

一百行按八比二切开，右边那一块全程不参与拟合。

四个返回值有固定顺序：先 x_train、再 x_test，然后 y_train、最后 y_test。接收的变量按这个顺序排，顺序排错不会报错，只会把训练集和测试集对调。

test_size=0.2 让两成进测试集，一百行里二十行。切出来的形状是 (80, 2) 和 (20, 2)，y 那两份是一维的 80 和 20。random_state=2 把随机种子钉死，每次运行切到的是同一批行，两个人的结果才能对上。

不写 random_state，每次运行就会换一批测试样本。换六十个种子各切一次，MSE 在 9.21 到 22.57 之间跳，中位数 16.20，标准差 2.81。这十几分的差距全部来自抽样，模型一行代码没动。所以报告里要给 MSE，就得连 random_state 一起给。

第三步：建三个模型，动作完全一样

三个类名不同，动作一模一样：先建一个评估器（estimator），再把训练数据喂给 fit。算法结构是人选的，模型参数是训练之后才有的，这一步之前，simple.coef_ 根本不存在。

三者的区别在目标函数。LinearRegression 只最小化残差平方和；Lasso 在目标上加一项 α 乘系数绝对值之和；Ridge 加的是 α 乘系数平方和。两个带惩罚的默认 α 都是 1.0，也就是不调参时它们已经在做正则化了。

系数都是正的：多选一门课加 1.88 分，每天多学一小时加 5.31 分。截距 −7.04 对应”一门课不选、一天不学”，这个样本并不存在，所以截距本身没有实际含义，它的作用是让直线能平移到合适的高度。

Lasso 的两个系数都比简单线性小，截距却更靠近 0，这是惩罚项在起作用：它把系数往 0 拽，拽多少由 α 决定。

第四步：预测，喂进去的必须是没见过的数据

predict 里传成 x_train，这一轮就白跑了

模型已经在训练集上拟合过，再把训练集喂回 predict，量到的是它记住训练集的程度。这份数据上训练集 R² 是 0.9287，测试集 0.9181，两个数差得不多，因为只有两个特征、样本也不多，模型没有余力去死记。换成特征几十个、样本几百个的表格，两者的差距会拉到两三成，那个漂亮数字就全是假的。
另一个更常见的症状是直接报错：x_train 有 80 行、y_test 只有 20 个，两边对不上，sklearn 会抛样本数不一致（inconsistent numbers of samples）。

第五步：评估，两个指标一起看

第一个参数永远是真实值 y_test，第二个是这个模型自己的预测值。三个模型三套预测，混着传会得到一张对不上的成绩单，而且不会报错。

模型 MSE R² 系数（门数 / 时长）
简单线性回归 14.401 0.9181 1.875 / 5.315
Lasso（α = 1） 14.948 0.9150 1.597 / 5.182
Ridge（α = 1） 14.394 0.9181 1.871 / 5.304

R² 0.9181 的意思是测试集上九成二的方差被模型解释掉了，剩下不到一成是没算准的。MSE 14.401 开根号是 3.79，单位回到分，也就是平均差三分八。两个指标说的是同一件事的两种刻度：MSE 带量纲，说得出”差几分”；R² 无量纲，跨数据集也能比。

三个数排下来，Lasso 的 MSE 比别人高 0.55。原因在系数那一列：α = 1 把 1.875 压到 1.597、5.315 压到 5.182，方向对，幅度过了。Ridge 的惩罚作用在平方上，对 1.9 和 5.3 这种量级的系数几乎没有影响，所以它的结果与简单线性分不开，小数点后第三位才见差别。

四根柱子，最后一根是调过参的 Lasso。

第六步：把真实值和预测值画在一起

subplot(3, 1, 1) 三个参数是行数、列数、第几个。竖排三幅就是 (3,1,1)、(3,1,2)、(3,1,3)，编号从左到右、从上往下数。写成 (1,3,1) 就是横排三幅，图会挤成三条窄带。

x_range 给横轴编 1 到 20 的号。np.arange(1, len(x_test) + 1) 里那个 +1 不能少：arange 的右端点是开区间，写到 20 只到 19，和 y_test 的 20 个值对不齐，plot 会直接报长度不一致。

格式串 'b-' 拆成两半：字母是颜色（b 蓝、g 绿、r 红），短横是实线。三幅图之间只改颜色、模型名和预测值这三处，其余照抄。抄完要逐行核一遍该改的都改了，颜色对、名字错这种错最常见。

灰点是二十个测试样本的真实分数，彩线是三个模型各自的预测。

三条线的走势几乎重合，都跟着真实值起伏，在第 9、15、17 个样本上偏得最远，最大的一个差了 7 分。线是折的，因为横轴排的是样本序号。横轴换成 hours 之后，同一批预测点才会重新排成一条直线。

第七步：调参，把最差的 Lasso 救回来

要调的只有一个数：Lasso 的惩罚强度 α。它是超参数（hyperparameter），不能从数据里解出来，只能试。试的流程是交叉验证（cross validation）加网格搜索（grid search）。

np.logspace(-4, 1, 15) 在 10⁻⁴ 到 10¹ 之间按等比取 15 个数，相邻两个差 2.27 倍。等比取是因为 α 的效果本来就在对数尺度上：10⁻⁴ 到 10⁻³ 之间的变化，和 1 到 10 之间的变化，对结果的影响是同一个量级。

param_grid 是一个字典，键写参数名，值写候选列表，名字要和评估器的参数名一字不差。cv=5 是五折：训练集 80 行切成 5 份，每次拿 4 份训练、留 1 份验证，跑五轮，五个分数取平均。留出法（从训练集里再切一小块当验证集）在样本少时不划算，切出来的验证集只有十来行，分数抖得厉害，所以这里用交叉验证。

横轴是候选的 α，纵轴是五折验证上的平均 R²，橙点是最高处。

从 10⁻⁴ 到 7.2×10⁻² 这一段，曲线基本是平的：十五个候选值里有九个给出同一个数 0.9171。这说明在这个区间内惩罚小到不影响结果，Lasso 退化成最小二乘。再往上才开始掉，0.164 处 0.9170，0.373 处 0.9167，0.848 处 0.9151，1.93 处 0.9076，4.39 处 0.8703，10 处掉到 0.7710。

最高点落在 10⁻⁴，正好是网格的左端点。这是个该警觉的信号：最优点卡在边界上，说明真正的冠军可能在网格外面，把下界放宽到 10⁻⁵ 再搜一次才有定论。本例停在 10⁻⁴，是因为再往下惩罚项小到只剩浮点误差，结果不会再变。

调完之后 Lasso 的 MSE 从 14.948 降到 14.401，与简单线性持平。救回来的是惩罚过强带来的那 0.55 分，模型本身的表达力一直是那条直线，没有变强。GridSearchCV 只负责挑超参数，它的 best_params_ 结尾带下划线，带下划线的属性都是训练之后才有的，和 coef_、intercept_ 一个道理。

注意 GridSearchCV 内部已经把五折跑完了，它的 best_estimator_ 就是拿最优 α 在全部训练集上重新拟合过的模型，可以直接拿来预测。上面又建了一个 Lasso(alpha=best_alpha)，是为了让 α 这件事在代码里显式出现一次。

第八步：拿新样本试一次

predict 要的是一张二维表，形状是（样本数，特征数）。np.array([3, 2]) 是一维的，长度 2，模型会把它当成两个样本一个特征。reshape(1, -1) 改成 1 行 2 列，-1 表示列数让 numpy 自己算。

选 3 门课、每天学 2 小时，预测 9.22 分；选 8 门课、每天学 7 小时，预测 45.17 分。两个数都落在 6.11 那张散点的带子里，没有跑到数据范围之外。

橙点是两个新样本的预测值，横坐标是每天的学习时长。

9.22 这个数可以对着数据核一下：真正每天学 2 小时的人，平均 11.48 分，模型只给 9.22。差的这 2 分来自门数，同样是每天两小时，选 3 门课的人在样本里分数偏低。模型算的是两个特征一起决定的位置。同一个时长的平均值只是它的近似。

小结

  1. 切分要钉种子：test_size=0.2 切出 80 / 20，random_state 让每次切到同一批行。
  2. 三个模型一套动作：建评估器、fit 训练、predict 预测，类名不同而已。
  3. 评估只在测试集上做：MSE 14.401、R² 0.9181，训练集上的 0.9287 不能当成绩。
  4. 调参搜超参数：α 从 10⁻⁴ 到 10¹ 选 15 个，五折交叉验证挑出 10⁻⁴，MSE 降到 14.401。
  5. 预测新样本先 reshape：np.array([...]).reshape(1, -1) 才对得上（样本数，特征数）。
