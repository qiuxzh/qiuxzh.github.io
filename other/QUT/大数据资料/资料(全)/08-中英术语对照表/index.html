08 中英术语对照表

qiuxz2026-11-162026-11-16
English 中文 一句话
data 数据 承载信息的各种符号的统称
structured data 结构化数据 存在固定字段里，先有模型后有数据
semi-structured data 半结构化数据 自带标签、自描述结构，如 XML / JSON
unstructured data 非结构化数据 无预定义模型，如图片、音频、视频
data model 数据模型 规定存哪些字段、什么类型
relational database 关系型数据库 MySQL / Oracle / SQL Server
XML / JSON 可扩展标记语言 / JS 对象表示 两种半结构化格式
information 信息 被解释、有上下文的数据
knowledge 知识 从信息中总结出的规律
wisdom 智慧 据知识做决策
DIKW model DIKW 模型 Data → Information → Knowledge → Wisdom
raw / clean data 原始 / 清洗后数据 加工链路的第 1、2 阶段
value-added / insight data 增值 / 洞见数据 加工链路的第 3、4 阶段
sensor data 传感器数据 机器自动产生，如地震、GPS
big data 大数据 超出传统存储与处理能力的数据集合
Volume / Variety / Velocity / Value 体量大 / 类型多 / 速度快 / 价值密度低 4V 特征
Veracity / Validity 真实性 / 有效性 第五个 V，数据可信
Volatility / Variability 易变性 / 可变性 扩展 V
sampling 抽样 被「全样」取代的旧方法
fault-tolerant 容错 接受少量混杂，换规模与速度
correlation / causality 相关 / 因果 「是什么」与「为什么」
paradigm 范式 共同体对本体论、认识论、方法论的承诺
data-intensive scientific discovery 数据密集型科学发现 第四范式
Garbage In, Garbage Out 垃圾进，垃圾出 数据质量决定结论质量
user portrait / profile 用户画像 给用户打标签，支撑广告变现
data life cycle 数据生命周期 采集→预处理→存储→分析→呈现
acquisition / preprocessing 采集 / 预处理 前两个阶段
ETL 抽取-转换-装载 Extract / Transform / Load
visualization 可视化 最后一步，辅助决策
batch / stream processing 批处理 / 流处理 等数据齐了算 / 边来边算
data silo 数据孤岛 系统间不联通，管理问题
data as a factor of production 数据要素 与土地、劳动力并列的生产要素
operating system 操作系统 管理硬件与软件资源的系统软件
kernel 内核 管进程、内存、驱动、文件系统、网络
kernel mode / user mode 内核态 / 用户态 用户不能直接操作内核
distribution 发行版 内核 + 一堆软件的打包
terminal / shell 终端 / 命令解释器 敲命令的地方与读懂命令的程序
root directory 根目录 /，Linux 没有盘符
absolute / relative path 绝对 / 相对路径 从 / 写起 / 从当前位置写起
permission 权限 r=4 w=2 x=1，755 即 rwxr-xr-x
symbolic link 符号链接 首字符 l，类似快捷方式
command mode / insert mode 命令模式 / 插入模式 vim 的两种基本模式
IDE 集成开发环境 编辑器 + 运行 + 调试
Jupyter Notebook 交互式笔记本 浏览器里边写边看结果
dynamically typed 动态类型 运行时才确定类型，不用声明
strongly typed 强类型 不自动隐式转换，类型不符报错
PEP 8 Python 编码规范 Style Guide for Python Code
docstring 文档字符串 三重引号的多行注释
list / tuple / set / dict 列表 / 元组 / 集合 / 字典 四种内置容器
list comprehension 列表推导式 一行完成筛选 + 变换
iterable 可迭代对象 能逐个取元素的对象
garbage collection 垃圾回收 自动内存管理
data acquisition 数据采集 从各类数据源获取数据的第一步
ETL 抽取 · 转换 · 装载 异构源到数据仓库之间的那段管道
heterogeneous data source 异构数据源 格式、结构各不相同的多个来源
data warehouse / data mart 数据仓库 / 数据集市 统一视图，供查询与分析
batch / real-time source 批量 / 实时数据源 攒一批再传 / 边产生边传
sensor network (WSN) 传感器网络 有线或无线，自动持续产生小数据
page view (pv) 页面访问量 同一个人刷新三次算三次
web crawler 网络爬虫 按规则自动抓取网页的程序
crawling strategy 爬取策略 URL 的抓取顺序
URL pool / seed URL 池 / 种子 待抓地址的队列
Robots Exclusion Protocol Robots 协议 站点根目录的 robots.txt 声明许可
DNS cache DNS 缓存 存下域名到 IP 的对应，减少解析时间
DFS / BFS 深度 / 广度优先 前者易不收敛，后者易撑爆 URL 池
PageRank 页面排名 按入链数量与质量给页面打分
Markov chain 马尔可夫链 分糖模型，收敛值与初始值无关
transition matrix 转移矩阵 邻接矩阵，描述节点间权重流向
DOM 文档对象模型 标签组成的树，抽取时在树上定位
XPath XML 路径语言 从节点 A 到节点 B 的路径表达式
regular expression 正则表达式 描述一类字符串的过滤逻辑
anti-crawler 反爬 识别非浏览器、封 IP、验证码、封号
distributed system 分布式系统 多台普通机器，对用户像一台
scale up / scale out 纵向 / 横向扩展 换更强的机器 / 加更多普通机器
distributed file system 分布式文件系统 跨多机管理文件与目录
namespace 命名空间 用目录树统一编址
NameNode / DataNode 主节点 / 从节点 管元数据 / 存真实数据块
block 数据块 2.x 默认 128 MB，1.x 为 64 MB
metadata 元数据 目录树、文件到块、块到节点
FsImage / EditLogs 镜像 / 编辑日志 全量快照 / 之后的增量修改
SecondaryNameNode 辅助节点 做 checkpoint 合并，不是备份
heartbeat / block report 心跳 / 块报告 报活（默认 3 秒）与报手里有哪些块
replica / replication factor 副本 / 副本因子 一份数据存几份，默认 3
rack awareness 机架感知 副本跨机架放，防整架断电
Write Once Read Many 写一次读多次 文件写入后不能修改
commodity hardware 普通商用硬件 便宜、不高可用，坏了就换
NoSQL 非关系型数据库 Not Only SQL，不保证 ACID
ACID 事务四特性 原子、一致、隔离、持久
CAP 一致性 / 可用性 / 分区容忍 三者不可兼得
BASE 基本可用 · 软状态 · 最终一致 放弃强一致之后的那条路
key-value / document 键值存储 / 文档型 Redis、Memcached / MongoDB、CouchDB
wide-column / graph store 宽列 / 图存储 HBase、Cassandra / Neo4j
row key 行键 HBase 的主键，表按它排序
column family 列族 建表时指定，是权限与存储的单位
column qualifier 列限定符 写数据时才确定，记作 family:qualifier
cell 单元格 由 row + column + version 唯一确定
time stamp 时间戳 区分同一单元格的多个版本
data preprocessing 数据预处理 把原始数据变成规整数据集
dirty data 脏数据 缺失、冗余、噪声、不一致、异常、错误
missing value 缺失值 忽略、填默认值、填均值、填同类均值、填最可能值
noise 噪声 值在真值附近抖动
binning 分箱 排序切箱，用箱内统计量替换
equal-width / equal-depth 等宽 / 等深 按距离切 / 按频数切
clustering 聚类 成簇，簇外的是离群点
regression 回归 拟合函数来平滑数据
outlier 异常值 明显偏离其余数据的值
3σ rule 3σ 规则 偏离均值超 3 倍标准差，概率小于 0.003
chi-square test 卡方检验 标称属性的相关性检验，看 p 值
correlation coefficient 相关系数 [-1, 1]，绝对值越大越相关
covariance 协方差 数值属性的相关方向
normalization 归一化 把不同量纲压到同一尺度
zero-mean standardization 零均值标准化 减均值除标准差，得均值 0 方差 1
min-max normalization 最小最大归一化 线性压到 [0, 1]，新数据要重定 min/max
unitization 单位化 除以自身模，只改幅度不改顺序
label / one-hot encoding 标签 / 独热编码 省内存但造顺序 / 造维度但不造顺序
discretization 离散化 连续值划区间，用区间替换
generalization 泛化（概化） 底层概念抽象到高层概念
data reduction 数据归约 缩减表示，结果几乎不变
feature selection 特征选择 逐步向前 / 向后 / 结合
PCA 主成分分析 k ≤ n 个正交主成分，按方差排序
DWT 离散小波变换 只存最强的一小部分系数
data cube 数据立方体 多维模型，n 维聚合成 n−1 维
data masking 数据脱敏 单向、无残留、易实现
data visualization 数据可视化 用图形呈现数据，用数据讲故事
Anscombe’s quartet 安斯库姆四重奏 四组数据摘要相同而形状不同
EDA 探索性数据分析 查数据质量、逐变量、查变量间关系
nominal / ordinal 定类 / 定序 只是名字 / 有顺序但间隔不等距
interval / ratio 定距 / 定比 零点人为 / 有绝对零点
bar chart 柱状图 离散数据之间比大小
histogram 直方图 离散类型的频数分布
line chart 折线图 看趋势
pie chart 饼图 占比，部分对整体
scatter diagram 散点图 两个连续变量的分布与关系
heat map 热力图 多个特征之间的关系
box plot 箱线图 取值的分布范围，含离群点
radar chart 雷达图 若干可比较的特征或能力的对比
kernel density estimation 核密度估计 不假设分布，用核函数平滑每个点
machine learning 机器学习 任务 T、表现 P、经验 E
supervised learning 监督学习 训练数据带已知标签
unsupervised learning 无监督学习 没有标签，找数据内在结构
semi-supervised learning 半监督学习 一部分有标签，一部分没有
reinforcement learning 强化学习 按动作后的奖励学策略
regression 回归 预测连续值
linear regression 线性回归 假设输出是输入的线性组合
least squares 最小二乘 让误差平方和最小
maximum likelihood 最大似然 让抽出这批样本的概率最大
overfitting 过拟合 把训练数据的噪声也当成规律
Occam’s razor 奥卡姆剃刀 能解释同一批数据时选最简单的模型
regularization 正则化 目标函数 = 损失 + 惩罚
L1 norm L1 范数 各元素绝对值之和，对应 LASSO
L2 norm L2 范数 各元素平方和开方，对应 Ridge
LASSO 最小绝对值收敛和选择算子 L1 惩罚，系数会被压到 0
Ridge 岭回归 L2 惩罚，系数被压小但不归零
logistic regression 逻辑回归 二分类首选，核心是 sigmoid
sigmoid function S 形函数 把实数压进 (0, 1)
k-nearest neighbor (kNN) k 近邻 找最近的 k 个实例，回归取均值、分类取众数
Minkowski / Manhattan / Euclidean distance 闵可夫斯基 / 曼哈顿 / 欧氏距离 p 可调 / p=1 / p=2
dichotomous variable 二元变量 只取 0 与 1
Jaccard index Jaccard 系数 非对称二元相似度，a/(a+b+c)
cosine similarity 余弦相似度 比方向不比长度，用于向量
decision tree 决策树 根节点放变量与分裂点，叶节点放输出
information gain 信息增益 ID3 的分裂判据
information gain ratio 信息增益率 C4.5 的分裂判据
Gini impurity 基尼不纯度 CART 的分裂判据
pruning 剪枝 预剪枝设最小样本数，后剪枝剪掉弱子树
random forest 随机森林 行 bootstrap、列随机抽特征，多树投票
ensemble learning 集成学习 把多个模型组合起来
clustering 聚类 无标签，从输入找簇结构
k-Means k 均值聚类 分配、更新中心、迭代到收敛
MSE / RMSE 均方误差 / 均方根误差 越小越好
covariance 协方差 符号表示线性相关的方向
coefficient of determination R² 可决系数 被模型解释的方差占比，越大越好
confusion matrix 混淆矩阵 TP / FP / TN / FN 四格
true positive (TP) 真正例 判为正，实际也是正
false positive (FP) 假正例 误报，第一类错误
false negative (FN) 假负例 漏报，第二类错误
precision 查准率 TP/(TP+FP)，判为正的里面真有多少
recall / sensitivity 查全率 / 敏感度 TP/(TP+FN)，正例里抓到多少
specificity 特异度 TN/(TN+FP)，负例里排除多少
F1 score F1 分数 precision 与 recall 的调和平均
ROC / AUC 受试者工作特征曲线 / 曲线下面积 TPR 对 FPR；AUC 0.5 到 1，越大越好
Rand index (RI) 兰德系数 聚类结果与真实划分的一致程度
silhouette coefficient 轮廓系数 (b−a)/max(a,b)，−1 到 1
Calinski-Harabaz index CH 指数 簇间离散除以簇内离散，越大越好
parameter / hyperparameter 参数 / 超参数 数据可估计 / 只能人来定
grid search 网格搜索 超参数候选值做笛卡尔积
random search 随机搜索 在取值范围内随机采样
K-fold cross validation K 折交叉验证 轮流做测试集，K 次取平均
data ethics 数据伦理 使用、处理、分析、共享时该守的原则
privacy 隐私 不愿被他人知道的敏感信息
security 安全 不受威胁，没有危险危害损失
data breach 数据泄露 数据被非授权地传播出去
data governance 数据治理 人 + 过程 + 技术的规范化数据管护
business asset 业务资产 数据在治理中的定位
