知识图谱概述

§1 知识图谱的构建方法

按构建方法分自顶向下与自底向上两类，领域应用中还有把两者结合的混合构建法。

  1. 自顶向下：从预定义的本体开始，先确定概念层次、关系类型与约束，再把实体按这个骨架填入。本体提供结构化和指导性的数据表示，适用于数据表示结构化、受控的场景，包括企业知识管理、医疗保健与医疗报告、金融服务、政府和公共管理、科学研究与学术。
  2. 自底向上：实体和关系从结构化元数据、非结构化与半结构化数据以及众包数据中提取，提取后逐步构建图谱结构。模式或本体基于数据开发，随新实体类型与新关系的发现逐步创建。
  3. 混合构建：领域实体关系多、变化快时，纯自顶向下难以覆盖复杂性，纯自底向上难以保证数据质量与完整性，两条路线结合使用。智慧农业与智慧消防的图谱都采用这种方式。

自顶向下先有本体后有数据，自底向上先有数据后归纳出本体，两者的分界在本体的形成顺序。

§2 发展历程，包括几个阶段

发展过程分五个阶段。

阶段 时间与标志 内容
萌芽 1965 年，Feigenbaum 提出专家系统 符号主义主张用逻辑表达模拟思维，基于领域知识库与推理机机制解决问题，这一阶段的知识库是知识图谱的雏形
工程化 1977 年第五届国际人工智能会议，Feigenbaum 提出知识工程 把数据、信息和知识整合到结构化的图形化知识表示中，目标是构建丰富、连贯、可操作的知识体系，支持搜索、推荐、智能问答
形式化 1991 年 Niches 提出知识本体概念，1993 年 Gruber 定义为概念体系的明确规范 把领域知识形式化，提供共享的语义框架，使概念有明确定义、可被计算机处理、可群体共享，为大规模工程实践奠定基础
互联网 1998 年 Tim Berners-Lee 在 WWW 十周年之际提出语义网 把传统人工智能与万维网结合，通过 RDF 在万维网中应用知识表示与推理；同期出现 DENDRAL 与 MYCIN 等大规模专家知识系统
知识图谱 2012 年 Google 正式提出知识图谱概念 建立增强搜索引擎功能的知识库，提出 Things, not Strings；与人工智能、大数据融合，构建走向半自动化与自动化，出现跨域知识整合

§3 知识图谱的分类，不同方式与类别

按四种方式划分，另有三类新兴类别。

按知识模态

  • 结构化：以明确定义的数据结构表示，常存于数据库，含事实和关系，可用 SQL 等标准查询语言检索和操作。
  • 半结构化：有部分结构形式，不具备严格数据模式，如 XML、JSON、标记语言。
  • 非结构化：以自然语言形式存在，缺乏明确结构和格式，如文本、图像、音视频等多媒体数据。

按领域开放性：通用、跨领域、垂直领域、企业内部四类。

按构建方法：自顶向下、自底向上，以及两者结合的混合构建法，见 §1。

按元数据实现方式

  • 基于模式（Schema）：预先定义模式来构建和管理数据，适合数据结构固定、规则明确、需要高效查询与推理的场景。
  • 基于本体（Ontology）：以本体定义概念、关系和属性，除实体与关系结构外还包含关系的语义和逻辑，能解释关联与层次结构。
  • 基于标签（Tags）：用标签描述和组织实体与关系，不依赖严格结构和预定义本体，添加标签即可描述实体特征和关系属性。

新兴类别

  • 时间知识图谱：$\varepsilon$、$R$、$\Gamma$ 分别为实体、关系、时间戳的集合，事实 $g\in\varepsilon\times R\times\Gamma$ 用四元组表示。
  • 空间知识图谱：在实体中加入时空属性，能查询某时刻或时间段内的实体关系，并可在一定程度上计算空间距离。
  • 多模态知识图谱：模态指某种类型的信息及其存储表示形式，如触觉、听觉、视觉、味觉、嗅觉。

§4 知识图谱的技术内涵、构建流程、各环节解决什么问题

内涵。知识图谱来源于语义网络，规模远大于常用的语义网络，把互相关联的实体及其属性组织在一起，统一组织结构化、半结构化和非结构化信息。节点代表实体，边代表关系，边的标签表示关系类型，由此形成三元组。实体是现实世界中的事物或概念，每个实体有唯一标识符和若干属性；属性是实体或关系的特性、描述；关系是实体之间的联系；本体对实体、属性和关系分类与定义，通常包含分类层次结构；语义指实体、属性和关系的含义；知识库是存储这三者的数据库或存储系统。

技术要素。表示、存储、抽取、融合、推理、问答、分析，另有众包、Scene Graph、Semantic IoT 等方向。

构建流程。图谱工程从结构化数据、半结构化数据、纯文本数据三类来源做知识提取，分别对应图谱融合、D2R 转换语义集成、Web Table 抽取、信息抽取四条落地路径，沉淀为概念、实体、关系、事实、事件、规则，由此形成概念抽取、实体抽取、关系抽取、事件抽取、规则抽取五类技术。各环节的作用如下。

环节 解决的问题
知识表示 用计算机可处理的形式描述知识，支持推理
知识抽取 从不同来源、不同结构的数据中提取实体、关系、事件
知识融合 消除同一实体的多种表述，统一模式层与数据层描述
知识存储 结构化、组织、联结信息，支持检索与多跳遍历
知识推理 由已有知识推出隐含关系，补全图谱
问答与分析 把关联关系用于搜索、问答、推荐与决策

知识图谱表示技术

§5 知识表示的内涵

知识表示（KR）用计算机模型和方法表示、处理知识，以支持推理、学习和决策等智能行为，其内容包括如何构造信息，使计算机能理解并利用这些信息模拟人的智能活动。它与数据格式、数据结构、编程语言分属不同层面，对人工智能而言，数据与知识的区别在于知识表示支持推理。

知识库的形成分知识认知、知识收集、知识表示、知识库建立、知识库维护五个阶段，知识表示处在中间环节。它应用于专家系统、自然语言处理、机器学习、智能搜索引擎与机器人，作用是提高推理能力、增强解释能力、促进知识共享。

Davis、Shrobe、Szolovits 在《What is a Knowledge Representation?》中把知识表示的用途归为五种角色。

角色 内涵
替代物 Surrogate 客观事物的机器标识（Entity ID）
本体约定集合 一组本体约定和概念模型
智能推理理论 支持推理的表示基础
高效计算媒介 用于高效计算的数据结构
人类表达媒介 人可理解的机器语言

§6 两类知识表示的原理、优势、局限、适用场景

两类指基于符号的知识图谱表示与基于向量的知识图谱表示。

符号表示。用节点和边描述实体及其关系，基本组成有节点、边、属性、三元组、类型。基于图的表示与建模分三级台阶：简单图，有向标记图（RDF 与属性图），OWL 与本体，表达能力逐级增强，推理能力逐级减弱。三种具体形式在下表中对照。

形式 原理 优势 局限 适用场景
属性图 节点表示实体或概念，边表示关系，节点与边都可带属性 工业界最常见的建模方法，图数据库可针对图结构做性能优化 不支持符号推理 工程建模与图数据库落地
RDF 用三元组（subject, predicate, object）描述资源，主语为实体，谓词为关系或属性，宾语为值或另一实体 W3C 的语义数据交换标准，语义逻辑基础严格，支持推理 需配合 RDFS、OWL 才能表达复杂语义 网络数据表示与交换
OWL 以类、属性、实例与逻辑关系对概念和关系做形式化建模 提供等价性、传递性、互反、函数性、对称性与局部约束等构件 表达构件多，建模与推理成本高 三元组无法满足语义表示需要时

早期符号表示。语义网络用有向图表示互连的节点与弧段，顶点代表概念，弧段表示概念间的语义关系，基本语义单元是三元组 $\langle 节点1, 关系, 节点2\rangle$。产生式系统以 IF P THEN Q 表达规则，P 为前提、Q 为结论或操作，附确定性因子 $CF\in[0,1]$。框架系统用槽（Slot）与侧面描述对象的属性，取值分槽值与侧面值。谓词逻辑写为 $P(X_1,X_2,\dots,X_n)$，P 为谓词名称，$X_i$ 为个体；描述逻辑是一阶谓词逻辑的可判定子集，含概念、关系、个体三个要素，知识库 $O=\langle T,A\rangle$ 中 TBox 存内涵知识、ABox 存断言知识。

方法 优势 局限
语义网络 结构性，把事物属性及语义联想显式表示；联想性，源自人类联想记忆模型；自然性，直观易懂，在自然语言理解中应用最广 无公认形式表示体系，含义依赖处理程序的解释，推理正确性无保证；表示手段多样导致形式不一致、检索复杂
产生式系统 采用人类常用的因果关系形式，直观且便于推理；规则形式相同，易模块化管理；可表示确定性、不确定性、启发性与过程性知识；格式固定，便于一致性检测 求解反复匹配、冲突消解、执行，规则库大时匹配费时；复杂问题易组合爆炸；不能表达结构性知识
框架系统 对知识的描述完整全面，知识库质量高，允许数值计算 构建成本高、质量要求高；表达形式不灵活，很难与其他形式的数据集关联使用
谓词逻辑 接近自然语言、易被接受，易表示精确知识；有严格的形式定义和推理规则，易于精确实现 无法表示不确定性知识，难以表示启发性知识及元知识；组合爆炸导致效率低、推理复杂度高

向量表示。把离散符号映射为稠密低维向量，实体与关系各学一个向量，用向量运算度量为三元组成立的程度。四类模型的思想与代表如下。

类别 核心思想 代表模型
基于向量空间距离 关系视为平移，或先投影到关系空间再平移，用 $\lVert h+r-t\rVert$ 度量 TransE、TransR
基于语义匹配 用神经网络编码实体与关系，在表示空间中匹配并打分 SMN、ESM
基于旋转与双曲几何 关系即复数平面或双曲空间中的旋转，约束 $t=h\circ r$ RotatE、RotH
面向动态知识图谱 引入时间切片、时间嵌入或时间向量，刻画知识随时间的演化 TGAT、TTransE

向量表示的优势是可直接计算、可做链接预测与图谱补全，能处理符号推理难以覆盖的海量三元组；局限在于表示结果缺乏符号层面的可解释性，训练依赖大量三元组。符号表示适合需要明确语义、可解释与可推理的场景，向量表示适合补全、链接预测与相似度计算。图嵌入与知识图谱嵌入也有分工：前者面向普通图的节点，学习局部与全局结构信息；后者面向带语义的三元组，把关系编码进向量。

§7 TransE 的内涵、评分函数、计算

内涵。TransE 把三元组 $(h,r,t)$ 中的实体与关系映射到同一个低维实向量空间 $\mathbb{R}^{d}$，把关系看作从头实体到尾实体的平移向量，要求成立的三元组满足 $h+r\approx t$。

评分函数。取 $h+r-t$ 的 $\mathrm{L1}$ 或 $\mathrm{L2}$ 范数，值越接近 0，三元组成立的程度越高。

$$f_r(h,t)=\left\lVert h+r-t\right\rVert_{L1/L2}$$

训练。整体目标为 margin 排序损失，$\gamma$ 为 margin，负样本由随机替换 $h$ 或 $t$ 构造，记 $S$ 为正例集合、$S’$ 为负例集合。

$$L=\sum_{(h,r,t)\in S}\sum_{(h^{\prime},r,t^{\prime})\in S^{\prime}}\max\bigl(0,\quad f_r(h,t)+\gamma-f_r(h^{\prime},t^{\prime})\bigr)$$

实体与关系先按 $uniform(-6/\sqrt{k},,6/\sqrt{k})$ 初始化并归一化；每轮取一个 batch，对每个正例采样一个损坏三元组，按 $\sum\nabla[\gamma+d(h+r,t)-d(h’+r,t’)]_{+}$ 更新嵌入。

计算。设 $h=(1,0,1)$，$r=(0,1,0)$，则 $h+r=(1,1,1)$。对三个候选尾实体分别求 $f_r$。

候选 向量 $h+r-t$ $\mathrm{L1}$ $\mathrm{L2}$
$t_1$ $(1,1,1)$ $(0,0,0)$ 0 0
$t_2$ $(0,1,1)$ $(1,0,0)$ 1 1
$t_3$ $(2,1,1)$ $(-1,0,0)$ 1 1

$t_1$ 的得分最低，判为正确尾实体；三个候选按得分排序为 $t_1 < t_2 = t_3$。$\mathrm{L1}$ 与 $\mathrm{L2}$ 在这组整数向量上给出相同排序。

TransR。实体映射到实体向量空间 $\mathbb{R}^{d}$，关系映射到关系向量空间 $\mathbb{R}^{k}$，且 $k\ne d$；每个关系配一个映射矩阵 $M_r$，先算 $h_r=hM_r$、$t_r=tM_r$，再在关系空间内满足平移关系。

§8 Skip-gram 核心思想

Skip-gram 用中心词预测上下文，逐个考虑窗口内的每个词。其依据是分布式语义假设。词的语义由它被使用的上下文确定。预测任务用于得到词向量。

计算流程。中心词的 one-hot 向量（长度 $V$）乘中心词矩阵 $v$（$V\times n$）得 $n$ 维隐藏层，再乘上下文矩阵 $u$（$V\times n$）得 $V$ 维向量，经 softmax 归一化后取概率最大的词为预测词；预测与上下文不符时用反向传播修正权重 $W$ 与 $W’$。

训练样本。对句子 “I always go to work by bus” 取窗口 2，中心词 work 的上下文为 go、to、by、bus，得到四个样本 $(work, go)$、$(work, to)$、$(work, by)$、$(work, bus)$。

与 CBOW 对照。

维度 CBOW Skip-gram
预测方向 用上下文预测目标词 用目标词预测上下文
结构 平均上下文词的向量后预测目标词 逐词预测上下文
特点 结构简单，训练效率高，能处理大规模语料 表达更细粒度，效果通常更好

两者共享同一套词向量参数，训练信号不同。图嵌入把随机游走得到的节点序列当作句子，节点当作词，沿用 Skip-gram 训练节点向量。

知识抽取

§9 知识抽取与命名实体识别的内涵

知识抽取的概念于 20 世纪 70 年代后期出现在自然语言处理领域，指自动化地从文本中发现并抽取相关信息，把多个文本碎片中的信息合并，把非结构化数据转换为结构化数据。从工程角度看，图谱构建就是从不同来源、不同结构的数据中提取知识并存入知识图谱。

数据来源分结构化数据（链接数据、数据库）、半结构化数据（表格、列表、Infobox）、纯文本数据三类，对应图谱融合、D2R 转换语义集成、Web Table 抽取、信息抽取四条落地路径。抽取出的知识在图谱中沉淀为概念、实体、关系、事实、事件、规则，由此形成概念抽取、实体抽取、关系抽取、事件抽取、规则抽取五类技术。

从文本获取知识有三个基础任务。术语抽取从语料中发现由多个单词组成的相关术语；命名实体识别检测实体边界并分类；关系抽取识别文本中实体之间的语义关系。

知识抽取分五个阶段。

阶段 内容
数据预处理 数据收集、数据清洗、数据标注。清洗去除重复与错误数据，标注为实体、关系等信息添加标签
实体抽取 命名实体识别确定实体边界与类型，实体扩展在已识别实体基础上抽取相关或相似实体
关系抽取 关系模式发现、特征提取（句法路径、词向量、上下文）、关系分类
事件抽取 事件触发词识别、事件论元抽取（参与者、时间、地点）
后处理与评估 结果校验（人工或自动审核、与已有知识库对比）、效果评估（准确率、召回率、F1 值）

各阶段并不完全独立，彼此可能存在交叉和重叠。

实体抽取又称实体识别，任务是从文本中识别代表实体的边界并判别其类型，范围包括人名、地名、组织机构名等命名实体，以及日期、时间、货币等领域特定实体。基本原理是对文本做语法和语义分析后识别并提取特定实体，常用方法分基于规则、基于统计（机器学习）、基于深度学习三类。

实体识别按序列标注建模：输入是特征序列，输出是类别序列，标签之间存在依赖；普通分类任务的输入 $X_1 \dots X_n$ 与输出 $Y_1 \dots Y_m$ 相互独立。深度学习方法以词的向量为输入，由网络充当编码器，经 CRF 输出每个词的标注结果，不依赖人工定义的特征。

§10 HMM 的 A、B、π

HMM 描述时间序列的统计模型，用于刻画含隐含未知参数的马尔可夫过程。模型记为 $\lambda=(A,B,\pi)$。

参数 名称 含义
$A$ 转移概率矩阵 $A_{ij}$ 表示从状态 $i$ 转移到状态 $j$ 的概率
$B$ 发射概率矩阵 $B_j$ 表示在状态 $j$ 下生成观测的概率
$\pi$ 初始状态概率 序列起始时刻各状态的概率分布

在命名实体识别中，每个词的标注是隐藏状态，词是观测序列；训练学到词与标注之间的概率分布，给定观测序列时预测最可能的标注序列，常用 BIOES 标注。由此对应三个基本问题，分别是概率计算、学习（参数估计）与解码。

HMM 在输出独立性假设下成立，当前输出仅依赖当前标签。CRF 对所有特征做全局归一化，可求全局最优，输出时依赖整个输入序列；线性链 CRF 含状态特征函数与转移特征函数，能处理标记之间的依赖关系，且不受输入数据长度限制。

§11 bot 模型的内涵

bot 这一名称的具体所指存疑。下面分别列出词袋模型、BERT、BiLSTM-CRF 的内涵。

BoW（词袋模型）。One-hot 编码与词袋模型的维度等于词典大小 $k$，向量稀疏，不携带词与词之间的相似性信息。词向量把维度压缩到 $d$，且 $d\ll k$，语义由上下文决定。

BERT。双向编码器表示（Bidirectional Encoder Representations from Transformers），基于 Transformer 架构的预训练语言模型。预训练用掩码语言模型（MLM）与下一句预测（NSP）在大规模无标文本上学通用语言表示；微调阶段在特定任务上加任务输出层，用少量标注数据调参。

BiLSTM-CRF。LSTM 用遗忘门、记忆门、输出门保护和控制细胞状态，BiLSTM 把前向与后向两个 LSTM 的输出拼接，捕捉每个位置更全面的上下文。输出经线性变换得到打分矩阵，矩阵元素表示某个字归入某个标签的分数；CRF 层建模标签之间的转移关系，按标签得分与转移得分之和找最高分路径，做全局最优解码。

§12 不同标签标注体系分别表示什么意思

序列标注先定标签体系，再选模型。三种体系的差别在标签集合的粒度。

  • IO：只用 I 标实体内部，用 O 标实体外部，不标实体起始位置。
  • BIO：B 标实体首字，I 标实体内部，O 标实体外部。
  • BIOES：在 BIO 上加 E（实体结束）与 S（单字实体），能区分多字实体的边界与单字实体。

同一段序列在三种体系下的标记如下，其中前三个位置构成一个人名，第六、七位置构成日期，第八位置是单字地名。

Token IO BIO BIOES
$w_1$ I-PER B-PER B-PER
$w_2$ I-PER I-PER I-PER
$w_3$ I-PER I-PER E-PER
$w_4$ O O O
$w_5$ O O O
$w_6$ I-DATE B-DATE B-DATE
$w_7$ I-DATE I-DATE E-DATE
$w_8$ I-LOC B-LOC S-LOC
$w_9$ O O O

三种体系的标签集合依次增大。大部分情况下标签体系越复杂准确度越高，训练时间也相应增加，需按实际情况选择。

§13 实体抽取：基于规则与基于机器学习的比较

规则式抽取。用预先定义的规则匹配、提取实体，规则可基于正则表达式、词典、语法模式定义。四个环节为规则制定（依据领域语法语义规则编写抽取规则）、文本解析（识别词性与句法结构）、规则匹配（把规则应用于解析后的文本，记录匹配片段的类型、位置与属性）、实体输出（用优先级或上下文消解规则冲突，输出 JSON 或 XML 等结构化信息）。典型做法是把文本与 ***说、***老师、***大学、***医院 等模板匹配。

基于机器学习的抽取。把抽取转化为二分类或多分类问题，对大量样本做特征编码、建模与训练，序列标注流程为确定标签体系、选择模型、定义特征、模型训练。特征分三类。词本身的特征（边界词概率、词性、依存关系）、前后缀特征（姓氏、地名的用字规律）、字本身的特征（是否为数字、是否为字符）。代表模型有 HMM、CRF、SVM。

维度 基于规则 基于机器学习
依据 人工编写的语言学规则与词典 标注数据中学到的特征与概率分布
优势 准确，有些实体识别只能依靠规则 可迁移到新文本，特征由数据驱动
局限 需要大量语言学知识，规则冲突需谨慎处理，构建费时费力，可移植性差 依赖标注数据的规模与一致性

知识存储

§14 知识存储的作用

知识存储通过结构化、组织、联结信息，让知识可访问、可利用。三个关键词是结构化（按统一模型组织知识）、组织化（建立分类与层次关系）、联结化（用关系把知识连成网络），目标是从数据走向可用的知识。只做收集与保存、不做组织的数据堆砌缺乏统一模型，查询靠人工翻找，无法支撑自动化分析与推理。

存储对象是实体、关系、属性。实体是图谱中独立的节点，关系是连接两个实体的有向边，属性是描述实体特征的值，三者构成三元组（头实体，关系，尾实体），这是知识图谱的基本构成单元。

四个核心价值如下。

价值 内容
检索效率 结构化组织快速定位知识，减少信息过载
决策质量 及时获取准确完整的信息，支撑决策
创新能力 整合分析发现新的连接，跨领域融合
可持续性 知识资源系统化沉淀，实时更新以适应变化

选型看四个维度。规模（实体与关系总量，单机还是分布式）、复杂度（关系是否多跳遍历、属性是否多值）、查询需求（简单过滤还是深度遍历，是否需内置图算法）、成本（存储与维护开销、团队技术栈成熟度）。

§15 两类知识图谱存储的比较

两类指基于关系型数据库的存储与基于原生图数据库的存储。

关系数据库的四种方案

方案 做法 优势 局限
三元组表 每个三元组映射为一行，表含 Subject、Predicate、Object 三列，在 Subject 与 Predicate 上建索引 无需额外建模，表结构直观，复用成熟关系库能力 表结构固定难表达复杂关系与多值属性，扩展需频繁改表，多跳查询要层层 JOIN
属性表 每个实体一行、每个属性一列 属性读写快，支持筛选、排序、聚合 实体类别多时表数量爆炸，同类实体属性差异大导致大量空值
二元表 一种关系一张表，只含头尾实体的 ID 关系结构清晰，可加列记录方向、权重、关系属性 语义靠列名与约定承载，图结构隐式表达
索引表 额外建表存索引键与主表记录引用 减少查询耗时，可定制专用索引 需要额外存储空间，高写入负载下维护开销大

属性表存实体属性、二元表存实体关系，通过唯一标识符关联，两者常协同使用。

原生图数据库。实体为节点、关系为边，存储结构与图同构。核心原理是免索引邻接。每个节点维护邻居的引用，访问邻接关系无需额外索引，查询时间与图整体规模无关，仅与搜索的局部大小成正比。物理存储分节点存储、关系存储、属性存储三类固定大小的存储块；属性可内联存储（属性小且查询频繁）或动态存储（属性大或不常查询）。图遍历六步为读取节点存储文件、定位起始节点、加载节点信息、按策略遍历邻居、预加载缓存加速、到达终止条件返回结果。Neo4j 用 Cypher 声明式查询，MATCH 定位、CREATE 创建、RETURN 返回，支持变长路径匹配。

知识融合

§16 知识融合的流程

知识融合整合来自不同来源的知识，消除同一实体的多种表述，统一模式层与数据层描述，输出一致、准确、无冗余的结果。目的有四个。消除概念混淆与命名冲突、清除重复实体与冗余关系、修正错误与矛盾的知识、支撑跨库查询推理与应用。

三类核心任务为实体链接（把文本指称映射到知识库实体）、知识对齐（建立两个图谱元素之间的对应关系，含本体对齐、实体对齐、属性对齐）、知识合并（把已对齐的知识写入同一图谱并消解冲突）。融合分两个层面。数据层融合处理实体与属性值，做实体对齐与匹配，输出等价实例对应关系；概念层融合处理概念、类与关系，做本体对齐与映射，输出等价概念对应关系。

基本技术流程分五步。

步骤 内容
数据预处理 语法正规化统一书写格式、拼接多字段做综合属性比较；数据正规化做移除特殊符号与多余空格、拼写纠错与大小写统一、标准化命名与单位换算、日期与数值类型转换
数据分块 把两两比较的 $O(n^2)$ 代价限制在块内。Hash 分块用单一键或多个键分别建块再取并集；Canopy 聚类用粗粒度距离与双阈值划块，$T1$ 宽决定块的最大范围，$T2$ 窄决定是否同块。分块键与块大小共同决定效率与召回率
记录链接 先算属性相似度，再判实体是否同一。属性相似度有编辑距离（字符串）、集合相似度（Dice、Jaccard）、向量相似度（TF-IDF）；实体相似度有聚合（加权平均、规则判定、分类器）与聚类（单链接、全链接、平均链接），另有表示学习方法
负载均衡 分块后各块大小不均，用多轮 Map-Reduce 把计算均匀分布到节点，Map 按块键分发记录，Reduce 做块内两两比较，输出候选匹配对
结果评估 用准确率、精确率、召回率、F1 值评估匹配结果，见 §18

记录链接中常用三种度量。编辑距离取两个字符串的最少插入、删除、替换次数，归一化用 $1-d/\max Len$；Dice 与 Jaccard 先把字符串切成 n-gram 集合，按集合交并计算；TF-IDF 权重等于词项频次 TF 与 $IDF=\log(N/\text{含该词文档数})$ 的乘积。

§17 知识合并

知识合并的前提是实体对齐已完成、等价关系已知。合并分两层。模式层整合类、属性、关系，数据层整合实体、属性值，产出规模更大、覆盖更全的新知识图谱。冲突指不同来源对同一事实描述不一致，类型有属性值冲突、关系冲突、结构冲突。

§18 混淆矩阵的计算

记 TP 为预测匹配且实际匹配，FN 为预测不匹配但实际匹配，FP 为预测匹配但实际不匹配，TN 为预测不匹配且实际不匹配。

预测匹配 预测不匹配 行合计
实际匹配 TP FN TP + FN
实际不匹配 FP TN FP + TN
列合计 TP + FP FN + TN 总数

四个指标为

$$ACC=\frac{TP+TN}{TP+TN+FP+FN},\quad P=\frac{TP}{TP+FP},\quad R=\frac{TP}{TP+FN},\quad F1=\frac{2PR}{P+R}$$

准确率 ACC 是整体判对的比例，精确率 P 是预测为匹配中正确的比例，召回率 R 是真实匹配被找出的比例，F1 兼顾两者。漏掉真实匹配的代价很高时，优先优化召回率。

代入 $TP=40$、$FN=10$、$FP=5$、$TN=45$，总数 100。

指标 计算 结果
ACC $(40+45)/100$ 0.850
P $40/(40+5)$ 0.889
R $40/(40+10)$ 0.800
F1 $2\times0.889\times0.800/(0.889+0.800)$ 0.842

图表示学习与图神经网络

§19 DeepWalk

图表示学习把图结构数据转换为低维向量表示，节点和边映射到低维空间，结构信息被压缩并保留，向量可直接用于计算、分类、聚类，目标是原始图中相似的节点在低维空间中也彼此接近。图数据节点与边没有固定顺序，邻接矩阵高维稀疏，CNN 与 RNN 都难以直接套用。典型应用有节点分类、链接预测、推荐系统。

DeepWalk 由 Perozzi 等在 KDD 2014 提出，受 word2vec 启发，第一个把自然语言处理思想用到图嵌入。类比关系是句子对应游走序列，单词对应节点，上下文对应邻域结构。随机游走可重复访问已访问节点，从任意节点开始按邻接表或转移概率矩阵随机选邻居移动，得到的路径作为训练嵌入模型的输入序列。

四步流程如下。

  1. 图输入，含节点索引、边索引、邻接矩阵。
  2. 对每个节点执行多次随机游走，生成大量节点序列。
  3. 把序列当作句子输入 Skip-gram，预测上下文节点。
  4. 反向传播更新参数，得到节点的低维向量表示。

优势是简单有效、易于实现，无需人工设计节点特征，在社交网络分析与推荐系统中表现良好。局限在于游走策略单一，倾向捕捉局部结构，可能忽略全局结构特征，游走长度与路径数量都会影响嵌入质量。

§20 GCN

GCN 即图卷积网络（Graph Convolutional Network），2014 年 Bruna 等把卷积操作扩展到图结构数据，2016 年 Kipf 与 Welling 提出简化的图卷积网络模型。图像、文本等欧几里得结构排列整齐、邻居数量固定，平移不变性与局部性原则成立，卷积核可在网格上滑动；图数据的节点连接模式不规则，每个节点的邻居数量与连接类型不同，CNN 依赖规则局部窗口、RNN 依赖序列顺序，都难以直接处理。图卷积把滤波器在局部邻域内加权求和换成节点与邻居之间传递信息，邻居数量可变，聚合方式统一。

层间传播公式为

$$H^{(l+1)}=\sigma\negthinspace\left(\tilde{D}^{-1/2}\tilde{A}\tilde{D}^{-1/2}H^{(l)}W^{(l)}\right)$$

$H^{(l)}$ 与 $H^{(l+1)}$ 分别为第 $l$ 层与下一层的节点特征矩阵，$\tilde{A}=A+I$ 为添加自连接后的邻接矩阵，$\tilde{D}$ 为 $\tilde{A}$ 的度矩阵，$W^{(l)}$ 为该层权重矩阵，$\sigma$ 为非线性激活函数。

自连接让节点在聚合时保留自身特征，$\tilde{A}H^{(l)}$ 聚合节点及其邻居的特征。对称归一化 $\tilde{D}^{-1/2}\tilde{A}\tilde{D}^{-1/2}$ 使每个节点的贡献与其度数成反比，避免高度数节点对结果过度影响，归一化后不同节点的聚合结果尺度一致，训练更稳定。

GCN 把卷积从欧几里得空间推广到图结构，训练流程简单清晰。局限是需要整张图参与训练，全图训练时内存开销受限，层数加深容易出现过平滑，节点表示趋于相似。复杂度为 $O(\lvert E\rvert F)$，其中 $F$ 为特征维度。

§21 GraphSAGE

GraphSAGE 由斯坦福大学与 Google 的研究者在 2017 年提出，解决大规模图数据上的归纳表示学习问题。直推式（transductive）方法只能在训练时见过的节点上预测，新节点加入往往需要重新训练，代表有 GCN、DeepWalk；归纳式（inductive）方法学到的是聚合规则，可为训练时未见过的节点生成嵌入，适合大规模、动态变化的图。

三步流程如下。

  1. 对每个节点的邻居做随机采样，可用固定大小的邻居采样，也可按节点度数自适应调整。
  2. 把采样到的邻居特征聚合起来，形成该节点的新特征表示。
  3. 在每个搜索深度 $k$ 重复上述过程，节点逐渐获得来自图中更远部分的信息。

三种聚合器为均值聚合（对邻居特征逐元素取平均，与 GCN 的卷积传播规则相近，可看作局部谱卷积的线性近似）、LSTM 聚合（表达能力强，LSTM 按顺序处理输入，需随机排列邻居以适应无序集合）、池化聚合（每个邻居向量先经全连接网络变换，再逐元素最大池化，对称且可训练）。

均值聚合的更新式为

$$h_v^{k}\leftarrow\sigma\negthinspace\left(\tilde{D}\cdot\mathrm{MEAN}\left(\left\lbrace h_v^{k-1}\right\rbrace\cup\left\lbrace h_u^{k-1},\quad\forall u\in N(v)\right\rbrace\right)\right)$$

池化聚合为

$$\mathrm{AGGREGATE}\sb{k}^{\mathrm{pool}}=\max\left(\left\lbrace\sigma(W_{\mathrm{pool}}h_u^{k}+b),\quad\forall u\in N(v)\right\rbrace\right)$$

与 GCN 的差别有三点。GCN 需要整张图参与训练，GraphSAGE 用小批量采样训练；GCN 属直推式学习，GraphSAGE 属归纳式学习，可为新出现的节点生成嵌入；GCN 对全部邻居加权求和，GraphSAGE 先采样固定数量的邻居，聚合函数可学习、可替换。

§22 GAT

GAT 基于注意力机制，在聚合邻居特征时给每个邻居分配不同的注意力权重，自适应地学习节点的重要性，在复杂结构与动态变化的图上表现出色。注意力机制由 QKV 三元组构成。Query 代表当前任务的需求，Key 与输入数据的特征相关联，Value 是输入数据的实际内容；Query 与 Key 的相似度决定每个 Value 的权重，加权求和即注意力的计算方式。

注意力系数经 softmax 归一化得到

$$\alpha_{ij}=\frac{\exp(e_{ij})}{\sum_{k\in N(i)}\exp(e_{ik})},\qquad e_{ij}=\mathrm{LeakyReLU}\left(a^{\top}\left[Wh_i\quad\Vert\quad Wh_j\right]\right)$$

$a$ 为可学习的注意力向量，$\Vert$ 表示向量拼接，$e_{ij}$ 为节点 $i$ 与 $j$ 之间的注意力分数。$\alpha_{ij}$ 越大，邻居 $j$ 对节点 $i$ 的影响越大。多头注意力把 $K$ 个头的结果合并，节点特征更新为

$$h_i^{\prime}=\sigma\negthinspace\left(\frac{1}{K}\sum_{k=1}^{K}\sum_{j\in N(i)}\alpha_{ij}^{k}W^{k}h_j\right)$$

GCN 依赖固定的邻接矩阵，对邻居统一赋权；GAT 的权重由节点特征算出，多头机制并行学习，对噪声邻居更鲁棒。复杂度为 $O(\lvert E\rvert F H)$，$H$ 为头数。

§23 GCN、GraphSAGE、GAT 三个模型的比较

三者都用拓扑结构学习节点表示，聚合过程遵循消息传递范式。对节点 $v$，先由邻居 $u$ 生成消息 $m_{vu}=M(h_v,h_u,e_{vu})$，再聚合 $m_v=\mathrm{AGG}({m_{vu},u\in N(v)})$，最后更新 $h_v’=U(h_v,m_v)$。差别在邻居怎么选与参数怎么学：GCN 把 AGG 固定为度归一化的加权和，GraphSAGE 换成可学习的均值、池化或 LSTM 聚合器，GAT 用注意力系数给每条消息加权。

模型 聚合方式 学习范式 关键特点 时间复杂度
GCN 对称归一化拉普拉斯聚合 直推式 全图批训练，依赖固定图结构，适合中小规模静态图；层数加深易过平滑 $O(\lvert E\rvert F)$
GraphSAGE 邻居采样加可学习聚合器 归纳式 支持 mini-batch，可推理未见节点，适合大规模动态图 $O(\prod^{K}N^{K}F)$
GAT 注意力加权求和 归纳式 多头注意力自适应赋权，适合邻居重要性差异大的图 $O(\lvert E\rvert F H)$

选型按数据条件定。有节点特征、图规模不大且结构固定，用 GCN；图很大或节点会新增，用 GraphSAGE 的采样加归纳；邻居重要性差异大、需要可解释的权重，用 GAT。
