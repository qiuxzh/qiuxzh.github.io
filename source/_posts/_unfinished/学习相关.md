| 层级  | 名称                | 核心定义                       | 范围特征                       |
| :-- | :---------------- | :------------------------- | :------------------------- |
| 第一层 | 一天的时间             | 自然时间维度的 24 小时总量            | 最宽泛的底层基数，无任何筛选             |
| 第二层 | 用来学习的时间           | 从 24 小时中划分出的、明确用于学习的时段     | 排除休息、娱乐、社交等非学习行为的时间        |
| 第三层 | 注意力集中的时间          | 学习时间内，专注度达标、无明显分心的时段       | 排除学习时走神、摸鱼、低效磨蹭的时间         |
| 第四层 | 主动思维的时间           | 集中注意力的时间内，进行深度思考、主动加工知识的时段 | 排除被动接收（如单纯翻书、听课时放空）的时间     |
| 第五层 | 用在拉伸区知识的时间、有效学习内容 | 主动思维时间内，针对 “跳一跳能掌握” 的知识的时段 | 排除舒适区（已会内容）和困难区（完全不懂内容）的时间 |

这个理论能串联起来几乎所有的学习方法

我们定义一个值，叫 **层级转化率** ，它是 第 i+1 层 与第 i 层的时间之比 

0.4（学习占比）、0.8（专注转化率）、0.7（主动认知转化率）、0.9（拉伸区投入率）

| 层级比值（第 i+1 层 / 第 i 层）         | 具体名称    | 意义解读                                       |
| ----------------------------- | ------- | ------------------------------------------ |
| 第二层 / 第一层<br>（学习时间 / 一天时间）    | 学习时间占比  | 衡量一天时间中分配给学习的比例，反映**时间分配的优先级**             |
| 第三层 / 第二层<br>（专注时间 / 学习时间）    | 专注转化率   | 衡量学习时间中真正集中注意力的比例，反映**学习时的专注度**            |
| 第四层 / 第三层<br>（主动思维时间 / 专注时间）  | 主动认知转化率 | 衡量专注时间中深度思考的比例，反映**认知投入的深度**               |
| 第五层 / 第四层<br>（拉伸区时间 / 主动思维时间） | 拉伸区投入率  | 衡量主动思维时间中聚焦 “跳一跳能掌握” 内容的比例，反映**学习内容的价值定位** |

我来用一些例子解释这个值

张三 每天学习 3小时，那第一层到第二层的层级转化率 =  3/24  =  1/8
李四 每天学习8小时

李四虽然每天学习时间更长，但是他专注力差专注，大部分时间在走神



过度的努力学习导致堕落
