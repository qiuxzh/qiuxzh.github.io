## 苏格拉底式学习

定义：由古希腊哲学家苏格拉底创立的思辨式学习 / 教学法，以**对话与提问**为唯一工具，通过持续反诘，让学习者暴露认知漏洞，自主建构知识与真理。


这是一个苏格拉底式学习的例子：

**学生**：
我觉得学习就是把知识记住。

**苏格拉底**：
1. 那你说，记住知识，就等于学会了吗？
2. 如果一个人把答案背得很熟，但遇到新问题完全不会用，你觉得他算学会了吗？
3. 那你认为，**学会**和**记住**，差别在哪里？
4. 你说学习是为了掌握知识，那掌握知识的目的，又是什么？
5. 如果知识不能帮你思考、判断、解决问题，它还算真正的知识吗？
6. 那你现在再想想：**真正的学习**，应该包含什么？

**学生**：
哦，我明白了，学习不只是记，还要理解、会用、能思考。

**苏格拉底**：
那你能给 “真正的学习” 下个定义吗？

**学生**：
真正的学习，是通过理解与思考，把知识变成自己解决问题的能力。


可以看到，苏格拉底式学习的核心在于一对一的对话，学生在不断的对话中思考和学习



适合场景：
+ 反思、复盘
+ 学习抽象概念


不适用纯记忆类的问题，比如
+ ”水的沸点是多少“、
+ ”英语单词apple是什么意思“
+ ”linux的ls命令有哪些参数？“




### 让AI当“苏格拉底”

提示词：
```
请以苏格拉底式对话与我交流，不直接给答案，只通过层层提问引导我独立思考、梳理逻辑、发现问题本质。聚焦我提出的话题，用简洁、有启发性的问题逐步追问，帮我澄清观点、反思前提、完善思考。
```

```
一、请对我的观点进行苏格拉底式的追问，至少问三个为什么
二、假设我的想法是错误的，你会从哪个角度去质疑我
三、我可能忽略哪些关键的前提和反例
```
