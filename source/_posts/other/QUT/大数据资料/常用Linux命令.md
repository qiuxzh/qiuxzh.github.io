## 一、用户与权限

| 命令 | 作用 | 说明 |
| --- | --- | --- |
| `useradd -m lmd` | 新建用户 | 需要 root 权限，`-m` 同时建家目录 |
| `passwd lmd` | 设置或修改用户密码 | 需要 root 权限，不带用户名时改当前用户 |
| `su - lmd` | 切换到指定用户 | `-` 同时切换环境变量和工作目录；root 切普通用户不用密码，反向要输 root 密码 |
| `chmod 755 run.sh` | 用数字改权限 | 755 = rwxr-xr-x |
| `chmod u+x run.sh` | 给属主增加执行权限 | u 属主、g 属组、o 其他人、a 全部，`+` `-` `=` 表示增、删、设 |
| `chown lmd:lmd a.txt` | 修改文件的属主与属组 | 需要 root 权限 |
| `sudo 命令` | 以 root 身份执行一条命令 | 普通用户访问 `/usr/local` 这类 root 目录时加 |

`ls -l` 第一列共 10 位，以 `-rwxr-xr-x` 为例：

| 位置 | 这一段 | 含义 |
| --- | --- | --- |
| 第 1 位 | `-` | 文件类型：`d` 目录、`-` 普通文件、`l` 符号链接 |
| 第 2–4 位 | `rwx` | 属主权限，r 读 4、w 写 2、x 执行 1 |
| 第 5–7 位 | `r-x` | 属组权限 |
| 第 8–10 位 | `r-x` | 其他人权限 |

`-rwxr-xr-x 1 lmd lmd 1024 Oct 30 10:00 run.sh` 依次是权限、链接数、属主、属组、大小、修改时间、文件名。

## 二、查看与目录

| 命令 | 作用 | 说明 |
| --- | --- | --- |
| `pwd` | 打印当前目录的绝对路径 | — |
| `whoami` | 显示当前登录的用户名 | — |
| `date` | 显示系统日期与时间 | — |
| `ls` | 列出目录内容 | 默认不显示以 `.` 开头的隐藏文件 |
| `ls -l` | 按详细格式列目录 | 权限、链接数、属主、属组、大小、时间；`ll` 是别名 |
| `ls -a` | 连隐藏文件一起列 | 隐藏文件以 `.` 开头 |
| `ls -lh` | 详细格式加易读大小 | 大小显示成 K、M、G |
| `cd 目录` | 进入指定目录 | 绝对路径 `/home/lmd` 或相对路径 `data` |
| `cd ..` | 回到上一级目录 | `.` 当前目录，`..` 上一级，`-` 上一次所在目录 |
| `cd ~` | 回到当前用户的家目录 | `~` 家目录，`/` 是根目录 |
| `mkdir 名` | 新建目录 | 父目录不存在时报错 |
| `mkdir -p a/b/c` | 连续建多级目录 | 父目录不存在会自动建 |
| `rmdir 名` | 删除空目录 | 目录非空时报错 |

## 三、文件

| 命令 | 作用 | 说明 |
| --- | --- | --- |
| `touch a.txt` | 新建空文件 | 已存在时只更新时间戳 |
| `cp 源 目标` | 复制文件 | — |
| `cp -r 源目录 目标` | 递归复制整个目录 | 不加 `-r` 会报「略过目录」，不复制内容 |
| `mv 源 目标` | 移动文件或目录 | 同目录内移动等同重命名，移动后源不存在 |
| `rm 文件` | 删除文件 | 没有回收站，删了不可恢复 |
| `rm -r 目录` | 递归删除目录及内容 | `rm -rf` 不提示直接删，`rm -rf /` 会毁掉整个系统 |
| `cat a.txt` | 一次输出整个文件 | 文件大时刷屏 |
| `less big.log` | 分页查看文件 | `q` 退出，`more` 类似 |
| `head -5 a.txt` | 显示前 5 行 | 不写 `-5` 默认 10 行 |
| `tail -f app.log` | 实时跟踪文件末尾 | 看滚动日志，`Ctrl+C` 退出 |
| `echo "hi" > a.txt` | 把内容写入文件 | `>` 覆盖，`>>` 追加 |

## 四、vim

| 操作 | 按键 |
| --- | --- |
| 进入插入模式 | `i` 光标前、`a` 光标后、`o` 下一行新起 |
| 回到命令模式 | `Esc` |
| 保存并退出 | `:wq` |
| 不保存强退 | `:q!` |
| 只保存不退出 | `:w` |

打开时在命令模式，要先按 `i` 才能打字；忘了 `Esc` 就敲 `:wq`，这四个字符会写进正文。

## 五、压缩与解压

| 命令 | 作用 | 说明 |
| --- | --- | --- |
| `tar -cvzf x.tar.gz 目录` | 打包并压缩 | c 创建、v 显示过程、z gzip、f 指定文件名，`-f` 后紧跟文件名 |
| `tar -xvzf x.tar.gz -C 目录` | 解压到指定目录 | x 解开、C 目标目录，该目录要已存在 |
| `tar -tzvf x.tar.gz` | 只看包内清单，不解压 | t 列目录 |

## 七、快捷键

| 操作 | 作用 |
| --- | --- |
| Tab | 补全命令或路径 |

## 八、自主练习

```bash
sudo mkdir -p /usr/local/software      # (1) 建目录，/usr/local 属 root
cd /usr/local/software                 # (2) 进入该目录
touch a.test                           # (3) 建文件 a.test
mv a.test ~/b.txt                      # (4) 移到主目录并改名 b.txt
ls -l ~                                # (5) 详细列出主目录
cd ~                                   #     先离开，否则删目录报「设备或资源忙」
sudo rmdir /usr/local/software         # (6) 删空目录，非空用 sudo rm -r
```
